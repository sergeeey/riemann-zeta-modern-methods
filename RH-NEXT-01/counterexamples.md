# counterexamples.md

## C1. Исключения положительной доли в окне недопустимы (уровень абстрактной леммы)
g(u) = e^{βu}·cos(γu), γ ≠ 0, θ < β ≤ 2. Φ(s) = ½·[1/(s−β−iγ) + 1/(s−β+iγ)].

Проверка условий PoleData вручную по определению:
- g измерима;
- |g| ≤ e^{2u};
- Φ — преобразование Лапласа g при Re s > β, в частности при Re s > 2;
- Z = {β ± iγ}, Re > 0, дискретно;
- Φ голоморфна вне Z;
- полюса простые, c = ½ ≠ 0, Im ρ ≠ 0, поэтому требование для вещественных полюсов пусто.

Заключение «∀ρ∈Z, Re ρ ≤ θ» ложно (Re ρ = β > θ). Значит `WindowHypU g θ δ` ложна.

Если выполнено (i), то E содержит {u : cos(γu) > C·e^{(θ−β)u}} внутри окна; доля этого множества в окне стремится к ½. Тогда ∫_E g⁺·e^{-θu} ≥ c·δ·U·e^{(β−θ)U}, что больше ½e^{ηU} при η < β−θ и большом U. Условие (ii) нарушено.

**Вывод:** никакая версия с E положительной (верхней) логарифмической плотности невозможна. Это острота классической теоремы Ландау о колебании; известность в литературе не проверялась.

**Ограничение:** g здесь не G_F для ζ. Пример показывает границу абстрактного критерия, а не гипотетический ноль ζ.
