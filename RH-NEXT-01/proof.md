# proof.md

**Статус:** доказательство математическое, строгое относительно леммы `Deduction.landau_window` из первоисточника. Машинной проверки самого утверждения нет (Lean и Mathlib мной не запускались).

## Предложение A (H1_v1): выводится из `WindowHypU`
Для данных η и U₀ выберем U* так, чтобы |C|·δ·U ≤ ½e^{ηU} при всех U ≥ U* (возможно, так как e^{ηU}/U → ∞). Применим предположение с U₀' = max(U₀, U*), получим U и E.

Определим R(u) = |C|·e^{θu}·1_{[U,(1+δ)U]\E}(u) + max(g(u),0)·1_E(u).

- R ≥ 0.
- g ≤ R на окне: вне E по (i) g ≤ C·e^{θu} ≤ |C|·e^{θu}; на E g ≤ max(g,0).
- R·e^{-θu} интегрируема на окне: первое слагаемое ограничено на компакте; второе измеримо (g измерима по PoleData.meas), его интеграл конечен по (ii).
- ∫ R·e^{-θu} = |C|·Leb(окно \ E) + ∫_E g⁺·e^{-θu} ≤ |C|·δ·U + ½e^{ηU} ≤ e^{ηU}.

Это в точности `WindowHypU g θ δ`. По `landau_window` все ρ ∈ Z имеют Re ρ ≤ θ. ∎

## Следствие B (размер исключительного множества)
Если на E выполнено g⁺(u) ≤ A·e^{au} с a ≥ θ, то условие (ii) следует из
Leb(E) ≤ e^{ηU − (a−θ)(1+δ)U} / (2A).

Доказательство: ∫_E g⁺·e^{-θu} ≤ A·∫_E e^{(a−θ)u} du ≤ A·Leb(E)·e^{(a−θ)(1+δ)U}, так как u ≤ (1+δ)U. ∎

Из PoleData.growth всегда доступно a = 2 (A = C₀).

## Следствие B′ (для реальных G_F: априорная экспонента 1)
Статья Alpöge (zeta-paper.pdf, Part II §1, абзац «Outside the window») сама отмечает: частное суммирование по Чебышёву даёт Σ_{n≤x} Λ(n)/n ≲ log x и поэтому |G(x)| ≲ x·log x при x ≥ 2 [VERIFIED: текст статьи]. Для G_F = G + Σ aᵢ·Re g_{χᵢ} (конечная комбинация, aᵢ > 0) оценка |g_χ(y)| ≤ Σ_{n≤y} Λ(n)(y/n−1) + y·|L′/L(1,χ)| ≲ y·log y следует тем же рассуждением [INFERRED, элементарно, в статье для характеров не выписано].
Значит g(u) = G_F(eᵘ) ≤ A·(1+u)·eᵘ для u ≥ 0, и в Следствии B можно взять a = 1 с множителем (1+u). Достаточно:
Leb(E) ≤ e^{ηU − (1−θ)(1+δ)U} / (2A·(2+δ)·U) при U ≥ 1.
Смысл: пока нет информации о G_F на E, кроме оценки Чебышёва, исключительное множество обязано быть экспоненциально малым по u (порядка Y^{−(1−θ)(1+δ)}). Ослабить это можно только дополнительной информацией о G_F на E, а не изменением критерия.

## Что не доказано
Оптимальный размер E между экспоненциально малым (B) и положительной плотностью (она запрещена, см. counterexamples.md). Промежуточная область открыта.
