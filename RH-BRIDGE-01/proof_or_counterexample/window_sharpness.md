# Оконный критерий: окна ограниченной длины и положительная плотность не годятся (контрпример)

Статус результата: `PROVED` (элементарное доказательство ниже) + `EXACT_COMPUTED` (проверка закрытой формулы, `verification/check_window_counterexample.py`). Новизна не заявляется: это классическая острота теоремы Ландау об осцилляции; в проекте близкий пример уже был в RH-NEXT-01 (`RH-NEXT-01/counterexamples`). Здесь формулировка привязана к параметрам оконного критерия (E1 карты зависимостей).

## Что уточняется

Критерий E1 (PDF Part II §1; Lean `Deduction.zeroFree_of_rpow_window`) использует окно `[Y, Y^{1+δ}]`, то есть по u = log x отрезок длины δU, растущий с U. Вопрос: какие свойства окна необходимы, если использовать только аналитические свойства преобразования Мелина F.

## Аналитические предпосылки критерия (то, что используется, когда окно задано)

(a) g измерима на [0, ∞), g(u) = O(e^{2u}); (b) F(s) = ∫₀^∞ g(u)e^{−su}du мероморфно продолжается в Re s > 0, его полюса в Re s > θ нереальные, F регулярно в каждой вещественной точке s > θ.

## Утверждение W1 (ограниченная длина окна)

Для любых 0 < θ < β ≤ 2 и γ > 0 существует функция g, удовлетворяющая (a) и (b), с полюсами при s = β ± iγ (Re = β > θ), такая что для любой длины L < π/γ и любого U₀ найдётся U ≥ U₀ с g(u) < 0 ≤ e^{θu} на всём [U, U + L].

**Доказательство.** Положим g(u) = e^{βu}cos(γu). Тогда |g(u)| ≤ e^{βu} ≤ e^{2u}, это (a). Для Re s > β
F(s) = ∫₀^∞ e^{(β−s)u}cos(γu) du = (s−β)/((s−β)² + γ²),
правая часть — мероморфная функция на ℂ с двумя простыми полюсами s = β ± iγ, оба нереальные, а на вещественной оси знаменатель (s−β)² + γ² ≥ γ² > 0, так что F регулярна. Это (b). Функция cos(γu) отрицательна на интервале (π/(2γ) + 2πk/γ, 3π/(2γ) + 2πk/γ), длина которого π/γ. При любом L < π/γ и любом k такой, что 2πk/γ + π/(2γ) ≥ U₀, окно [U, U + L] внутри этого интервала при подходящем U лежит в области g < 0 ≤ e^{θu}. ∎

В терминах x = e^u: условие G(x) ≤ x^θ на [Y, e^L·Y] с фиксированным отношением e^L < e^{π/γ} не исключает полюс правее θ.

## Утверждение W2 (положительная плотность хороших u)

В том же примере множество {u : g(u) ≤ e^{θu}} содержит {u : cos(γu) ≤ 0}, то есть имеет логарифмическую плотность не меньше 1/2 (для больших u множество g(u) ≤ e^{θu} — это cos(γu) ≤ e^{(θ−β)u}, плотность стремится к 1/2). Значит условие «плохое множество имеет нулевую плотность» нельзя заменить на «хорошее множество имеет положительную плотность». `PROVED` (то же доказательство).

## Что остаётся открытым

W3 (`OPEN`). Минимальный рост длины окна L(U) в классе функций с условиями (a), (b): для сколь угодно медленно растущей L(U) → ∞ критерий может оказаться верным или нет. Аргумент PDF и Lean требует L(U) ≍ δU. Пример W1 даёт нижнюю границу L ≳ 1/γ_min только для функций с одной парой полюсов; для бесконечных сумм по нулям вопрос не решён. Попытка перенести доказательство на σ = σ(U) → ∞ упирается в то, что полюс и оценка Коши зависят от σ равномерно в U; я эту зависимость не выписал, поэтому результата нет.

## Что это значит для миссии

Гипотеза H2 в форме «заменить длинные хорошие интервалы плотностью или усреднением» опровергнута как чисто аналитическое утверждение: нужен именно длинный (растущий в u) интервал, либо исключительное множество экспоненциально малой меры (RH-NEXT-01: Следствие B′, известный результат Mahatab–Mukhopadhyay, arXiv:1512.03144, Thm 3.4). Расстояние между «экспоненциально малой» и «положительной плотностью» не исследовано.
