## A1. Три упрощения (hexagon:2611.00828v1) — `SOURCE_TRACED`, `CONDITIONAL`

Статус самой работы: «Primarily AI-generated text», автор предлагает аргументы как «proofs on paper»; проверка заявлена как «independent Codex review» (не человеческое рецензирование). Автор сам оговаривает: построение подъёмов (theta lifts) и оценки, дающие интервалы, берутся как входные данные. Следовательно, утверждения A1 условны относительно арифметической части Alpöge–Claude. `CONDITIONAL`.

Что в нём утверждается (конкретные формулировки из `three_simplifications.tex`):

1. **Потеря логарифма в сравнении наклонов решёток** (§2, Proposition «Integrated rank loss»). При `E[a] ≥ s`, `a ≤ s+U`, `λ_j ≥ s−H`, `0 ≤ d < 1` оценка `s − μ(C) ≤ ((η_f+4√e_f)H + 4D(U,H))/(1−d)`, `D(U,H)=UH/(U+H)`; оценка `∫₀ᴴ r(t)dt ≤ D(U,H)` точная в классе распределений с заданными средним и верхней границей. Выигрыш относительно релиза: вместо `4(Ū+b)log(1+B/b)/(1−d̄)` стоит `4D(Ū,B)/(1−d̄) ≤ 4Ū/(1−d̄)`. Вход — оценка ранга из Lean `Formalism/HarderNarasimhan/HarderNarasimhanProofs/TheoremFSharp` (эта же оценка — Lemma 4.2 Zhang, см. A2).
2. **Сравнение сумм по простым на одном масштабе** (§3–4, Theorem «th:average» и Corollary «cor:source»): сравнительные веса `a/x`, явно взвешенное среднее порядков дифференцирования, допускается больший разброс весов, показатель оценки сохраняется; коэффициент `1/(3o+1)` в `𝒢_ψ = G₁ + (1/(3o+1)) Σ_{ξ∈𝓕_ψ, ξ≠1} Re G_ξ` объяснён подсчётом смежных классов.
3. **Вывод отсутствия нулей из классической теоремы осцилляции** (§5, Proposition «An upper bound on power intervals» + Theorem «th:chain»): если вещественная функция `g` локально интегрируема, её преобразование Меллина `M_g` мероморфно продолжается в `Re s>0`, каждый вещественный полюс в `(θ,∞)` прост с положительным вычетом и `g(x) ≤ Kx^θ` на `[Y, Y^λ]` для сколь угодно больших `Y` (`λ>1` фиксировано), то `M_g` голоморфно при `Re s>θ`. Приём для вещественного полюса: вычитание `r_β x^β (1 − cos(u log x))` заменяет вещественный полюс парой невещественных `β ± iu` с тем же вещественным центром. Используется Kaczorowski–Pintz, Acta Math. Hungar. 48 (1986), 173–185: знакоперемена в каждом `[T^{1−α}, T]`. Интегральный вариант (`lemmaL` в Lean) выводится по формуле `M_A(s) = ((2^s−1)/s) M_g(s)`.

Совпадения с уже имеющимся в H-12 (`window_sharpness.md`, `check_window_counterexample.py`): тот же критерий E1/`zeroFree_of_rpow_window`; тот же приём «вычесть положительный вычет»; условие «положительный вычет» у A1 — явная гипотеза, в моей формулировке (a),(b) оно тоже есть.

Что нового для H-12:
- **Новое, для переиспользования:** точная форма `D(U,H)` и пример «половина наклонов на s−1, половина на s+1» (`r(t)=1/2`, площадь 1/2 против log 2 у огибающей) — это конкретный механизм, которого нет в `bridge_candidates.md`.
- **Не новое, не повторять:** критерий окна `[Y,Y^λ]` (мы доказали, что ограниченные окна не годятся, см. `critical_dependencies.md` §B3); трюк `1−cos`; теоремы Kaczorowski–Pintz как таковые.
- **Что A1 не меняет:** показатель `1/2+ε` и арифметические входы. A1 не касается `SizeKRel` и `MIstar2`; поэтому он не снимает ни одну из зависимостей миссии B.

Применимость к H-12: A1 даёт чистое описание «оболочки» E1 и лишний повод не использовать её как кандидата на улучшение. Элементарную часть (`D(U,H) ≤ U·log(1+H/U)`, интеграл `E min{H,(s−a)₊}` и точность на двухточечном распределении) я перечитал и не нашёл в ней ошибки, но численно и в Lean её не проверял (`NOT_RUN`); остальное в A1 опирается на арифметические входы Alpöge–Claude.

## A2. Заметка Zhang (preliminary note) — `SOURCE_TRACED`, `CONDITIONAL`

Автор прямо пишет: текст получен из вывода GPT 6 Pro и переписан за один день; «cannot claim that this summary is a faithful translation of the Lean code». Оглавление: §1 обзор (с. 3), §2 нули из сумм по степеням простых (14), §3 восстановление сумм из делимости автоморфных периодов (19), §4 оценка сумм (23), §5 знаменатели через когомологии Галуа (52), §6 выбор параметров (64). Ссылок на проверку человеком нет.

Что взято для работы: **Lemma 4.2** (с. 41–42): при `Σ‖K_i − I‖²_HS ≤ e·R`, `e ≤ 1/4`, `Tr(Q²) ≤ (1+η)Tr(Q)²/D`, `Σ codim E_i ≤ εR` коразмерность в `H` суммы `ΣB_iE_i` не превосходит `(η + 4ε + 4√e)·D`. Это то же утверждение, что в Lean `TheoremFSharp` и в A1, формула (rank): `(1−d)q(t) ≤ η_f + 4√e_f + 4r(t)`.

Одно ослабляемое предположение выбрано и исследовано в миссии C (`candidate_lemma.md`): условие `Σ‖K_i − I‖²_HS ≤ eR` с `e ≤ 1/4` заменено на два операторных условия `K_i ≤ (1+κ)I` и `Σ Tr K_i ≥ (1−e')R`. Результат — Lemma Z+ с оценкой `w ≤ D(η + 2(1+κ)ε/(1−e'))`, где член `4√e` исчез. Статус: `PROVED` на бумаге (набросок в `candidate_lemma.md`), алгебраическое завершение — `KERNEL_CHECKED` (`proof_or_counterexample/LemmaZAlgebra.lean`), операторная часть — `NOT_RUN` в Lean; численный тест без нарушений (`lemma_test.log`). Новизна **не проверена** по литературе: возможно, это стандартный факт о кадрах. Не заявлять как новый результат.
