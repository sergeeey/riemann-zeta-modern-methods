## Утверждение (novelty_claim)

```yaml
novelty_claim:
  object: claim (теорема о явной последовательности; доказана в Lean для lagA, см. b4_06_kernel_report.md)
  proposition: >
    Пусть ℘(z) = z^{-2} + Σ_{n>=1} a_n z^{4n-2} — функция Вейерштрасса кривой y^2 = x^3 - x
    (g2 = 4, g3 = 0; лемнискатический случай). Для любого простого p ≡ 3 (mod 4), n0 = (p+1)/4,
    n1 = p*n0: числа p*a_{n1} и a_{n0} p-целые, a_{n0} — p-адическая единица и p*a_{n1} ≡ -a_{n0} (mod p).
  equivalent_forms_to_treat_as_the_same_claim:
    - "a_n = (4n-1) * 16^n * H_n / (4n)!,  H_n — числа Гурвица (H_1 = 1/10, H_2 = 3/10) [INFERRED, проверено на n=1,2 по значениям из памяти]"
    - "соотношение между G_{p+1} и G_{p(p+1)}, G_{4k} = Σ' (m+ni)^{-4k}, на решётке Z[i]"
    - "соотношение между коэффициентами логарифма/экспоненты формальной группы кривой y^2 = x^3 - x в p, инертном в Z[i] (суперсингулярная редукция), индексы (p+1)/4 и p(p+1)/4"
    - "коэффициенты ряда Тейлора лемнискатического синуса sl(z) или косинуса cl(z), индексы 4n0 и 4n1 (с точностью до явных множителей)"
  required_difference: >
    Прежний источник, где утверждено то же соотношение для той же пары индексов (n0, p*n0) с точностью до
    явной перенормировки (множители факториалов, 16^n, (4n-1), степени периода), либо общая теорема,
    из которой оно следует подстановкой индексов без нового содержательного шага.
  non_novel_if:
    - same_exact: то же соотношение для тех же индексов найдено в источнике (в любой нормировке)
    - known_by_specialization: общий опубликованный результат (Хонда / Аткин–Суиннертон-Дайер / Двор / Катц / Гурвиц-Куммер)
      даёт его после проверки арифметики индексов; тогда результат НЕ новый, новой может быть только формализация
    - same_mechanism_other_curve: то же соотношение и тот же механизм (исключительный коэффициент + Фробениус) опубликованы для другой
      CM-кривой/формальной группы высоты 2, так что случай y^2 = x^3 - x — прямая подстановка
  verdict_vocabulary:
    - known_exact
    - known_by_specialization
    - no_material_overlap_found_within_audited_boundary   # никогда не "новое доказано"
    - recall_failure
```
