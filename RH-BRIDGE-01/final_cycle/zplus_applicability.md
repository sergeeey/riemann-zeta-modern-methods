# zplus_applicability.md — применимость Lemma Z+ к `TheoremFSharp` (этап A2, 2026-11-23)

**Вердикт: `CONDITIONAL / NOT_APPLICABLE_WITH_CURRENT_ASSUMPTIONS`** для Lemma Z+ в виде `K_i ≤ (1+κ)I`, `ΣTr K_i ≥ (1−e')R`. Направление Z+ закрыто как условная абстрактная лемма.
Побочный результат: HS-вариант («Теорема A» внешнего обзора) применим с теми же гипотезами, что у Lean, но даёт только константу, не показатель.

L0: структурное (детерминированная линейная алгебра); о нулях ζ ничего не утверждается. Исходник: `riemann-hypothesis-lean` @ `7cbf7a0c32fca1badf05931879a37c3f8a2b03b4` (`~/h12/rh/src`), проект не изменялся и не пересобирался.

## 1. Что есть в Lean (`SOURCE_TRACED`, чтение исходника)

- `Formalism/HarderNarasimhan/StatementFrameF.lean`, `FrameLA1`: гипотезы `Σ hs2(frK(c_i)(B_i) − id) ≤ e·ΣR_i`, `0 ≤ e ≤ 1/4`, `0 ≤ η`, `Tr(Q²) ≤ (1+η)(Tr Q)²/D`, `Σ(dim V_i − dim Nτ_i) ≤ ε·ΣR_i`. Вывод: `finrank (⨆ Nτ_i.map B_i)ᗮ ≤ (η + 4ε + 4√e)·D`. Это Lemma 4.2 Zhang. Доказана: `frame_linear_algebra_first`.
- `TheoremFSharp` (там же) и `theoremFSharp_of` (`HarderNarasimhanProofs/TheoremFSharp.lean:168`) применяют `FrameLA1` к `Nt τ i := hnStep …`, с `ε(τ) = u/(u+τ)` (`hcor`), и интегрируют по `τ ∈ [0, HH]`. Результат: `s − (1−δ)⁻¹(4u·log(1+HH/u) + (η+4√e)·HH) ≤ muDef b' X' cc`.
- Источник `e` и `η` в производственной цепочке: `ramification_linear_case_holds` (`ChainSlopeWindows/JointDModelAppliesUnitLattice.lean:164`, `RamLin` в `FrameTraceRatioFinEquiv.lean:149`). Там `√e0 ≤ sg/2`, `sg ≤ 1/20`, итоговое `e = 2·e0`, `η = 5·sg + 3√de`. Вход `InputSG` (`FrameTraceRatioFinEquiv.lean:30`) содержит только `hsSq(K_i − 1) ≤ e0·|ι_i|`, оценку взаимных следов и `|α| ≤ (1+η1)·D*`.
- **Оператор-ограничения `‖K_i‖_op ≤ 1+κ` в цепочке нет, и нижней оценки `ΣTr K_i ≥ (1−e')R` как отдельной гипотезы тоже нет.** Эти условия ни в `FrameLA1`, ни в `TheoremFSharp`, ни в `InputSG` не присутствуют.

## 2. Сопоставление предпосылок

| предпосылка Z+ | есть в Lean? | что следует из имеющегося |
|---|---|---|
| (1) `K_i ≤ (1+κ)I` | нет | только `‖K_i − I‖_op ≤ ‖K_i − I‖_HS ≤ √(e0·r_i)` (`PROVED_MATH`, одна строка), то есть `κ_i ≤ √(e0·r_i)`: растёт с размерностью `r_i = |ι_i|`; равномерной границы на `r_i` в `InputSG` нет (`OPEN`: из исходников не установлено) |
| (2) `ΣTr K_i ≥ (1−e')R` | не как гипотеза | следует: `e' ≤ √e` (Коши–Шварц), `PROVED_MATH` |
| (3) изотропия `Tr Q² ≤ (1+η)t²/D` | да (`hF1`) | совпадает |
| (4) `Σ codim ≤ ε·R` | да (`hcor`, `ε = u/(u+τ)`) | совпадает |

Контрпример к отказу от (1) из `candidate_lemma.md` (`kappa_necessity.py`, `EXACT_COMPUTED`) показывает, что без оператор-ограничения Z+ ложна. Подстановка `κ = max_i √(e0·r_i)` даёт множитель `(1+κ)`, который при больших `r_i` хуже исходной оценки `4ε + 4√e`. Условия (1)–(2) и условие Zhang `Σ‖K_i−I‖²_HS ≤ eR` по параметрам несравнимы (внешний обзор, контрпример 3; согласуется с `candidate_lemma.md` §3).

**Недостающая посылка для Z+:** равномерная оценка `κ`, то есть `sup_i ‖K_i‖_op ≤ 1+κ` с `κ` ограниченным независимо от `r_i`. Её нет в `InputSG`; выводить её из высотных оценок не пытался (потребовало бы нового анализа цепочки, вне бюджета).

## 3. HS-вариант (Теорема A) — применим, но выгода только константная

Утверждение (гипотезы идентичны `FrameLA1`): при `Σ‖K_i−I‖²_HS ≤ eR` (`e<1`), `Σ codim ≤ αR`, `Tr Q² ≤ (1+η)t²/D` для `x = w/D`, `a = (α+√(αe))/(1−√e)`:

`x − √(η·x(1−x)) ≤ a`, откуда `x ≤ η + 2a`.

- **Доказательство** (`PROVED_MATH`, на бумаге, перепроверено мной шаг за шагом): `B_i*T ⊆ E_i^⊥` ⇒ `Tr(P_T Q) ≤ Σ Tr(P_{E_i^⊥}K_i)`; `Tr(P K) = codim_i + Tr(P(K−I)) ≤ codim_i + √codim_i·‖K_i−I‖_HS`; Коши–Шварц по `i` даёт `≤ R(α+√(αe))`. Далее `t ≥ R(1−√e)`; `Tr(P_T Q) = t·x + Tr((P_T − xI)(Q − tI/D)) ≥ t(x − √(η x(1−x)))`, так как `‖P_T − xI‖²_HS = D·x(1−x)` и `‖Q − tI/D‖²_HS ≤ η t²/D`.
- **Сравнение с Lean/Zhang:** при `e ≤ 1/4` имеем `2a ≤ 4(α+√(αe))`, а при `α ≤ 1` это `≤ 4α + 4√e`; при `α > 1` исходная оценка тривиальна. Значит, Теорема A (бумажно) влечёт `FrameLA1` и усиливает её: член `4√e` заменяется на `4√(αe)`.
- **Численно** (`zplus/check_theoremA.py`, `.log`): 4000 случайных экземпляров с `e ≤ 1/4`, фактическими `e`, `η`, `α`, случайными подпространствами: нарушений **0**, `max(lhs − a) = 1e-15` (`NUMERICALLY_CHECKED`). Отношение старой к новой оценке на части `(α,e)`: минимум 1,30, медиана 1,97.
- **После интегрирования по `τ`** (`ε(τ) = u/(u+τ)`), в режиме производственных параметров `e = sg²/2`, `η = 5·sg`, `sg ≤ 1/20`: общая скобка `(η + √e-часть)·` уменьшается в 1,2–1,5 раза (`NUMERICALLY_CHECKED` как арифметика выражений; перечень точек в `check_theoremA.log`). Доминирует неизменный член `η·HH ≈ 5·sg·HH`, поэтому порядок по `sg` остаётся `O(sg)`; **показатель не меняется** (`INFERRED`, из формы выражения, не из Lean-цепочки).
