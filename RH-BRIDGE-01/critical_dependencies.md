### Классификация 14 соотношений (`EXACT_COMPUTED`, `verification/sizekrel_exponents.py` + `.log`)
Модель: `m = x^μ`, `n = x^ν`, `k = x^κ`, окна `SizeM/SizeN/SizeK` с центрами `(1/2 − ε/16, 2 + 8ε, 9/2 + 10ε)` и допуском `ϑ = ε/100`; `L = x^ε`, константы и логарифмы — показатель 0; проверка по 8 углам окон, точная арифметика дробей. **Область применимости:** только порядок показателей; неизвестные константы `C_Γ` и размер `log rdE` не моделируются.

| № | соотношение | запас (угол с минимумом) | класс |
|---|---|---|---|
| 1 | `x^{szTh} m⁵ f L x^ε ≤ k` | `93/400·ε` | **BINDING** (запас → 0 при ε → 0) |
| 2 | `8 C_Γ m⁵ f L ≤ k` | `497/400·ε` | **BINDING** (тот же показатель `5μ+ν`) |
| 3 | `k ≤ √x·n·rankBudget` | `497/100·ε` | BINDING по показателю, но **следует из 4** (остаток `421/400·ε ≥ 0`) |
| 4 | `√(k/m) ≤ rankBudget` | `1559/800·ε` | **BINDING** |
| 5–14 | `m²L ≤ k`; `m√x log x ≤ k`; `x^{szTh}m⁶L ≤ k log k`; `x^{szTh}m³L log rdE ≤ k log²k`; `log f ≤ √rS`; `log²f ≤ m²L`; `x^{szTh} loglog b ≤ r f log r`; `x^{szTh}L ≤ f log k`; `f ≤ m²n`; `f ≤ r²` | положительный запас порядка `x^{ε⁰}` (1/4 … 13/2) | **автоматические** на уровне показателей |

Вывод (`PROVED` в смысле показателей, из таблицы): три существенных ограничения — 1/2 (одно по сути), 4 и их следствие 3; остальные десять не ограничивают размеры, пока окна `SizeM/N/K` выполнены. Совместность 1 и 4: `k ≥ x^{szTh} m⁵ f L x^ε` и `k ≤ m n² x^{−2ε}` дают `n ≥ x^{4μ+4ε+ϑ}`; нужное `ν ≥ 2 + (94/25)ε`, у окна `SizeN` центр `2 + 8ε`: запас `(106/25)ε`. При `ε → 0` точка `(μ,ν,κ) = (1/2, 2, 9/2)` делает 1, 2, 4 равенствами (запас 0), поэтому показатель `1/2` в этой схеме не улучшается за счёт размеров.

**Что значит «слабеемое».** Классификация говорит о роли соотношения в системе показателей, но не о том, где оно используется в Lean: какое именно из 14 условий нужно данной теореме `f_mul_m_le` и другим потребителям, я не определял (`OPEN`); для этого нужна декларационная зависимость.

**Исправление прежнего утверждения.** В `bridge_candidates.md` (H4) ограничивающим указан член (A) `k/n² ≤ x^{1/2}`. Точнее: ограничивающее условие — соотношение 4 `SizeKRel` (`√(k/m) ≤ rankBudget`); с членом (A) оно совпадает только при `ε = 0`. Систему из `bridge_candidates.md` читать с этой поправкой.

## B3. Критерий окна: что именно опровергает `e^{βu}cos(γu)`

База: Lean `Deduction.zeroFree_of_rpow_window` (30 модулей), критерий E1 (PDF Part II §1), А1 Proposition «upper bound on power intervals»: хорошие интервалы `[Y, Y^λ]`, `λ>1` фиксировано, то есть по `u = log x` отрезок длины `(λ−1)U`, **пропорциональной** `U`.

Предпосылки, с которыми ниже работают контрпримеры (из `window_sharpness.md`): (a) `g` измерима, `g(u) = O(e^{2u})`; (b) `F(s) = ∫₀^∞ g(u)e^{−su}du` мероморфно продолжается в `Re s > 0`; вещественные полюса правее `θ` простые с положительным вычетом (в примерах вещественных полюсов нет).

| Вариант критерия «хорошо на `{g ≤ e^{θu}}`» | Статус | Доказательство |
|---|---|---|
| **W1.** Окна ограниченной длины `L` по `u` (произвольное фиксированное `L`) на сколь угодно далёких позициях | **REFUTED** (`PROVED`; `KERNEL_CHECKED` в `WindowSharpness.lean`) | `g = e^{βu}cos(γu)`, `γ < π/L` |
| **W2.** Хорошее множество положительной плотности | **REFUTED** (`PROVED`, `EXACT_COMPUTED`) | тот же `g`: `{cos ≤ 0}` плотности 1/2 |
| **W2′ (усиление).** Хорошее множество плотности, сколь угодно близкой к 1: для любого `ρ<1` | **REFUTED** (`PROVED` + численная проверка) | `g_N(u) = e^{βu}(F_N(γu) − 1)`, `F_N` — ядро Фейера (ниже) |
| **W-int.** Интегральный вариант (`lemmaL`): мажоранта `R ≥ g` с `∫R v^{−θ}dv/v ≤ Y^η` на **ограниченных** окнах | **REFUTED** | на хорошем отрезке берём `R = 0`; тот же `g` |
| **E1 / KP.** Окна длины `≥ cU` | **НЕ опровергается** — это сам критерий (доказан у A1 и в Lean) | — |
| **W3.** Окна длины `L(U) → ∞` сколь угодно медленно | `OPEN` | см. ниже |

**Новое в этой миссии (W2′).** Пусть `F_N(t) = Σ_{|j|≤N}(1−|j|/(N+1))e^{ijt} = sin²((N+1)t/2)/((N+1)sin²(t/2))` и `g_N(u) = e^{βu}(F_N(γu) − 1)`, `0<θ<β≤2`, `γ>0`. Так как `F_N − 1` не имеет нулевой частоты, преобразование
`Φ(s) = Σ_{0<|j|≤N} c_j/(s − β − ijγ)`, `c_j = 1 − |j|/(N+1)`,
мероморфно на `ℂ`, полюса `β + ijγ`, `j≠0` **невещественные**, вещественных полюсов нет; (a) выполнено (`|g_N| ≤ N e^{βu}`). Далее `F_N(t) ≤ 1/((N+1)sin²(t/2)) ≤ 1` при `sin²(t/2) ≥ 1/(N+1)`, и значит `g_N(u) ≤ 0 ≤ e^{θu}` вне множества меры `(2/π)·arcsin(1/√(N+1))` на период. Плотность хорошего множества `≥ 1 − (2/π)arcsin(1/√(N+1)) → 1` при `N → ∞`; **при этом полюса правее `θ` есть** (при `β>θ`). Следовательно никакого «критерия плотности `ρ<1`» не существует. `verification/check_density_counterexample.py` + `.log`: тождество ядра (ошибка ≤ 1.5e-12), замкнутая форма преобразования против численного интеграла (ошибка ≤ 2.8e-9), нарушений неравенства `(*)` на сетке 0; доля `g>0` при `N = 3, 10, 40`: 0.308, 0.136, 0.066 (гарантированная верхняя граница 0.333, 0.195, 0.100). Статус: `PROVED` (неравенство ядра Фейера и мероморфность — элементарны), численная проверка — `[VERIFIED]` (скрипт); в Lean не формализовано (`NOT_RUN`).

**W3 — почему не решено, и что именно известно.** Если полюса на линии `Re s = β` дают равномерно почти периодическую функцию `K(u)` со средним 0 (абсолютно сходящийся ряд частот), то для любого `u₀` с `K(u₀) > 0` найдётся относительно плотное множество почти-периодов, и `K > 0` встречается с ограниченными промежутками: **для такого класса** окно фиксированной длины `ℓ(K)` всегда содержит положительную точку, но `ℓ` зависит от `K` и неограниченно по классу (W1). Чтобы окна `L(U) → ∞` не хватало, нужно бесконечно много частот со спектром, уходящим в бесконечность, и неравномерно почти периодическое поведение; ни доказательства достаточности, ни контрпримера у меня нет (`OPEN`). Единственный выбранный альтернативный критерий для B3: **W2′** (плотность `→ 1`), он опровергнут. Критерий «плотность ровно 1, или окна `L(U) → ∞`» остаётся открытым и не решается без привлечения арифметической структуры `G`.

**Что это даёт для оценки E1.** Требование пропорциональной длины окна у E1 не техническое: короче нельзя ни по длине (W1), ни по плотности (W2′) в общем классе функций с условиями (a),(b). Арифметика Alpöge–Claude даёт именно окна `[Y, Y^{3/2}]` (A1, Theorem «th:chain»), то есть пропорциональные. Результат касается класса функций `g`, а не конкретной `G(x)`: для конкретной `G` с дополнительной структурой (явная формула) критерий мог бы быть слабее; это не исследовалось.
