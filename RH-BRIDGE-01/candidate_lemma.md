# candidate_lemma.md — Lemma Z+ (ослабление Lemma 4.2 Zhang / `TheoremFSharp`)

Миссия H12-UNIFIED-RESEARCH-01, миссия C. Уровень L0: **структурное/детерминированное** утверждение линейной алгебры; ничего о распределении нулей не доказывается.
Статусы: `PROVED` (бумажное доказательство, ниже), `KERNEL_CHECKED` (только алгебраическое завершение), `EXACT_COMPUTED`, `NOT_RUN` (операторная часть в Lean), `OPEN` (новизна, применимость).

## 1. Базовая лемма (что ослабляется)

Источник: Zhang, preliminary note, Lemma 4.2 (с. 41–42); тот же шаг в Lean `Formalism/HarderNarasimhan/HarderNarasimhanProofs/TheoremFSharp` и в A1 как формула `(1−d)q(t) ≤ η_f + 4√e_f + 4r(t)`.

**Lemma Z (как у Zhang).** Пусть `H = ℂ^D`, `B_i : ℂ^{r_i} → H` (`i = 1..m`), `γ_i > 0`, `K_i = γ_i B_i* B_i`, `Q = Σ γ_i B_i B_i*`, `R = Σ r_i`. Пусть `Σ ‖K_i − I‖²_HS ≤ e·R` (`e ≤ 1/4`), `Tr(Q²) ≤ (1+η) Tr(Q)²/D`, и подпространства `E_i ≤ ℂ^{r_i}` с `Σ codim E_i ≤ ε·R` (`ε ≤ 1`). Тогда `codim_H(Σ B_i E_i) ≤ (η + 4ε + 4√e)·D`.

Проверено в этой миссии только численно (95 случайных наборов, 0 нарушений, `proof_or_counterexample/lemma_test.log`); доказательства Zhang я не перепроверял построчно (`SOURCE_TRACED`).

## 2. Кандидат

**Lemma Z+ (Утверждение).** В тех же обозначениях, при условиях

1. `K_i ≤ (1+κ)·I` для каждого `i` в смысле операторного порядка (`κ ≥ 0`);
2. `Σ_i Tr K_i ≥ (1 − e')·R`, `0 ≤ e' < 1`;
3. `Tr(Q²) ≤ (1+η)·Tr(Q)²/D`, `η ≥ 0`;
4. `Σ_i codim E_i ≤ ε·R`;

для `w := codim_H(Σ B_i E_i)` выполнено

```
w − √(η·D·w) ≤ a·D,   a := (1+κ)·ε/(1−e'),
следовательно  w ≤ D·(√η + √(η+4a))²/4   и   w ≤ D·(η + 2a).
```

Кванторы: для всех `D, m, r_i ≥ 1`, всех линейных `B_i`, всех `γ_i > 0` и всех `E_i`; константы `κ, e', η, ε ≥ 0` произвольные, `e' < 1`. Никаких ограничений вроде `e ≤ 1/4`, `ε ≤ 1` не нужно (при `ε > 1` утверждение тривиально).

### Доказательство (`PROVED`, на бумаге; операторная часть — `NOT_RUN` в Lean)

Пусть `T = (Σ B_i E_i)^⊥ ⊂ H`, `dim T = w`, `P_T` — ортопроектор, `t = Tr Q = Σ Tr K_i ≥ (1−e')R`.

*Верхняя оценка.* Для `y ∈ T`, `e ∈ E_i`: `⟨B_i* y, e⟩ = ⟨y, B_i e⟩ = 0`, значит `B_i* T ⊆ E_i^⊥` и `B_i* P_T = P_{E_i^⊥} B_i* P_T`. Тогда
`Tr(P_T Q) = Σ γ_i ‖B_i* P_T‖²_HS ≤ Σ γ_i ‖P_{E_i^⊥} B_i*‖²_HS = Σ Tr(P_{E_i^⊥} K_i) ≤ Σ ‖K_i‖_op · dim E_i^⊥ ≤ (1+κ) Σ codim E_i ≤ (1+κ)·ε·R`.

*Нижняя оценка.* Пусть `Q̄ = (t/D) I`. Тогда `Tr(P_T Q) = t·w/D + Tr(P_T (Q − Q̄))`, и по Коши–Шварцу в HS `|Tr(P_T(Q−Q̄))| ≤ √w · ‖Q − Q̄‖_HS`, где `‖Q − Q̄‖²_HS = Tr Q² − t²/D ≤ η t²/D`. Значит `Tr(P_T Q) ≥ t·(w/D − √(η w/D))`.

*Сведение.* `t(w/D − √(ηw/D)) ≤ (1+κ) ε R` и `t ≥ (1−e')R` дают `w/D − √(ηw/D) ≤ a`, то есть `w − √(ηDw) ≤ aD`. Алгебраическое следствие (`w ≤ D(√η+√(η+4a))²/4` и `w ≤ D(η+2a)`) доказано в Lean 4 для вещественных чисел: `proof_or_counterexample/LemmaZAlgebra.lean`, теоремы `zplus_alg_sharp`, `zplus_alg_cor`, оси: `propext, Classical.choice, Quot.sound` (`KERNEL_CHECKED`, Lean v4.33.1, Mathlib `0df444a3`, вывод в `verification/LemmaZAlgebra.out`). Часть «след и проекторы» в Lean **не формализована** (`NOT_RUN`).

## 3. Сравнение с базой

| | Lemma Z (Zhang) | Lemma Z+ |
|---|---|---|
| условие на `K_i` | `Σ‖K_i − I‖²_HS ≤ eR`, `e ≤ 1/4` | `K_i ≤ (1+κ)I` и `ΣTr K_i ≥ (1−e')R` |
| вывод | `w ≤ D(η + 4ε + 4√e)` | `w ≤ D(η + 2(1+κ)ε/(1−e'))` |
| член `√e` | есть, не убирается по ε | отсутствует |
| точность | не исследована | `η`-член и `ε`-член достигаются (ниже) |

Связь условий: из `Σ‖K_i−I‖²_HS ≤ eR` по Коши–Шварцу `Σ|Tr(K_i − I)| ≤ Σ√r_i‖K_i−I‖_HS ≤ √R·√(eR) = √e·R`, то есть `e' ≤ √e` (`PROVED`, одна строка). **Но** условия 1–2 из условия Z не следуют: оператор-ограничение `κ` нужно вводить отдельно. Леммы несравнимы по гипотезам; Z+ даёт выигрыш (`2ε(1+κ)/(1−e')` вместо `4ε + 4√e`), когда `κ` ограничено, а `e'` мало.

## 4. Точность и барьеры

- **Член `η` и член `ε` точны.** Одно отображение `B = I_D`, `E` коразмерности `εD`: `K=I (κ=0), e'=0, η=0, w = εD`, а `zplus_alg_sharp` даёт `D·(√4ε)²/4 = εD`: **равенство** (`EXACT`). Для `η`: `Q = P_S`, `dim S = (1−ν)D`, `ε=0`: `w = νD`, `η = ν/(1−ν)`, отношение `w/(Dη) = 1−ν ∈ {0.90, 0.95, 0.99}` для `ν = 0.1, 0.05, 0.01` (`lemma_test.log`, численно).
- **Оператор-ограничение `κ` нельзя убрать, оставив одну след-оценку** (`EXACT_COMPUTED`, `proof_or_counterexample/kappa_necessity.py`, `.log`). `H=ℂ²`, `n+1` одномерных отображений: `n` штук `= e₁`, одно `= √n·e₂`; `Q = diag(n,n)`, `η = 0`, `e' = 0`, `E`: убить только последнее, `ε = 1/(n+1)`, `w = 1`, `D = 2`. Оценка «без κ» дала бы `w ≤ 4/(n+1)`, что неверно при `n ≥ 4`. Это **локализованный барьер**: без верхней оценки на `‖K_i‖` лемма ложна; с `κ = n−1` выполняется.
- **Что не установлено.** (i) Новизна: в литературе по кадрам и плотности подпространств возможен тот же факт; поиск не выполнялся. (ii) Применимость: в Lean-цепочке `TheoremFSharp`/A1 неизвестно, дают ли высотные оценки ограничение `‖K_i‖_op ≤ 1+κ` с ограниченным `κ`; не проверялось. (iii) Какого-либо влияния на показатель `1/2+ε` нет: изменение касается константы при `ε` и устранения члена `4√e_f` в формуле A1, не показателя.
