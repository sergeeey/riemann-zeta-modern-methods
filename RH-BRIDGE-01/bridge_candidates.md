# Кандидаты в леммы-мосты: формулировки, критерий, статус (H12-BRIDGE-DISCOVERY-01)

Дата: 2026-11-22. Все утверждения относятся к схеме Alpöge–Claude в изложении PDF (21.11.2026) и Lean-коммиту `7cbf7a0`. Статусы: `PROVED`, `KERNEL_CHECKED`, `EXACT_COMPUTED`, `SOURCE_TRACED`, `CONDITIONAL`, `OPEN`, `REFUTED`, `NOT_RUN`. Ссылки E1…E7 — рёбра `bridge_dependency_map.md`.

**Единый критерий сравнения.** (i) выводится ли конкретная целевая лемма; (ii) какие предпосылки нужны; (iii) насколько независимо доказательство от Lean-архива; (iv) проверяемо ли оно инструментом.

## Часть 1. Минимизация предпосылок аналитического перехода (E1)

### H1. Нужна ли оценка в каждой точке окна, или хватит интегрального ограничения?
- **Теорема-кандидат T1.** Пусть g измерима, g(u) = O(e^{2u}), F(s) = ∫₀^∞ g e^{−su}du продолжается мероморфно в Re s > 0 с нереальными полюсами в Re s > θ и регулярна на вещественной полуоси s > θ. Пусть при σ ≥ 252 для сколь угодно больших U и j = j(U), ближайшего к (5/4)(σ−2)U, выполнено ∫₀^∞ max(g(u),0)·u^j e^{−σu}/j! du ≤ C(σ−θ)^{−j}. Тогда F не имеет полюсов в Re s > θ.
- **Результат.** Это в точности шаг «(1.1) ⇒ противоречие с полюсом» PDF (p. 27); доказательство использует только эту интегральную оценку. Поточечная оценка на окне — достаточное условие для неё. В Lean то же сделано в виде `WindowHypU` с мажорантой R ≥ max(g, 0) (RH-NEXT-01, `SOURCE_TRACED`). **Вывод: поточечность не нужна, эффект известен.** Статус: `SOURCE_TRACED`; новизна: нет.

### H2. Можно ли заменить длинные хорошие интервалы условием плотности или усреднения?
- **Теорема-кандидат T2 (плотность).** Если множество u с g(u) ≤ e^{θu} имеет положительную логарифмическую плотность для сколь угодно больших масштабов, то полюсов правее θ нет.
- **Результат.** `REFUTED`. Контрпример g(u) = e^{βu}cos(γu), β > θ: `proof_or_counterexample/window_sharpness.md` (W2). То же для окон ограниченной длины по u (W1): `PROVED`, числа проверены (`verification/check_window_counterexample.py`).
- **Что остаётся.** Окно фиксированного отношения 1+δ при любом δ > 0 (так в Lean). Исключительное множество внутри окна экспоненциально малой меры допустимо (RH-NEXT-01, известный результат Mahatab–Mukhopadhyay, arXiv:1512.03144, Thm 3.4). Промежуточный случай (L(U) → ∞ медленно, меры между экспоненциально малой и положительной плотностью): `OPEN` (W3).

### H3. Какие свойства весов простых сумм необходимы в аналитическом выводе?
- **Что нужно, по тексту PDF §§3–5.**
  1. Неотрицательность коэффициентов c(r) = (1 − χ_d(r)) log p ≥ 0 и взятие положительной части (a/r − w)₊: тогда каждое слагаемое — допустимый показатель e_p ≥ 0 в неравенстве (II.3) Σ e_p log p ≤ log|Δ|.
  2. Точное тождество (5.3): P_{u,t,j} − M_{u,t,j} = Σ_i w_i R_i(a/w_i) выполняется для любых положительных весов (PDF p. 30: «identities of section 5 hold for any positive weights»).
  3. Два масштаба: выделенные клетки с w ∈ [b, b + O(b/(nx²))], остальные клетки с a_t/w_i ≥ exp(x^ε/3)/3, чтобы оценка C (5.6) превращала их вклад в o(1) (II.25), (II.26).
  4. Линейность отображения «сумма → остаток после вычитания α y log y + β y» (5.5).
- **Результат.** Аналитическому выводу нужны: неотрицательность, два разделённых масштаба и малое возмущение выделенных весов. Никакая арифметическая структура весов (кроме делимости из (M)) не используется. Статус: `SOURCE_TRACED` (чтение), новизна: нет.

### H4. Можно ли исключить часть количественных условий, сохранив произвольно малый показатель ошибки?
Система показателей из (A) и условий размеров. Пусть m = x^μ, n = x^ν, k = x^κ, ε → 0.

| № | Условие | Откуда | Ограничение на показатели |
|---|---|---|---|
| 1 | x/m ≤ x^{1/2} и m ≤ x^{1/2} | члены (A), (II.16) | μ = 1/2 |
| 2 | xm/k ≤ x^{1/2} и m²/k ≤ 1 | члены (A), (II.15) | κ ≥ 1 |
| 3 | k/n² ≤ x^{1/2} | член (A) | κ ≤ 2ν + 1/2 |
| 4 | 8·C_G·m⁵·f·x^ε ≤ k, f = 2n | `SizeKRel`, PDF p. 136 (III.233 и далее) | κ ≥ 5μ + ν |
| 5 | n = 2^e, x^{2+8ε} ≤ n ≤ 2x^{2+8ε} | PDF §4.1, p. 30; Part III.3 | ν = 2 |

- **Следствие (элементарно, `PROVED`).** Из 1, 3, 4: 5μ + ν ≤ κ ≤ 2ν + 1/2, то есть ν ≥ 5μ − 1/2 = 2 при μ = 1/2. При ν = 2 отрезок допустимых κ вырождается в точку κ = 9/2: условия 3 и 4 одновременно обращаются в равенство. Это объясняет, почему в источнике реальные размеры сдвинуты: m ≈ x^{1/2−ε/16}, n ≈ x^{2+8ε}, k ≈ x^{9/2+10ε} (PDF p. 136, `SizeM/SizeN/SizeK`). Само PDF отмечает, что округлённые размеры m ≈ √x, n ≈ x², k ≈ x^{9/2} из §I.8 условие `SizeKRel` не удовлетворяют (дают 2x^{9/2+ε}), `SOURCE_TRACED`.
- **Что показывает система.** Показатель итоговой оценки max(1−μ, μ, 1+μ−κ, κ−2ν) не меньше 1/2 при любом μ; значение 1/2 достигается только при μ = 1/2. Показатель 1/2 нельзя улучшить в этой схеме и, независимо, нельзя улучшить вообще: G(x) = Ω(x^{1/2}) (явная формула). Условие 4 (рост k как m⁵·n) и условие 3 (потолок k/n²) сходятся в критической точке; ни одно из них нельзя убрать, не потеряв условие 3 или 4 в виде ограничения снизу на n.
- **Что видно в Lean (чтение исходников, `SOURCE_TRACED`).** Условия размеров собраны в `SizesAt` (`src/Formalism/SharpRestriction/ElevenLe.lean:~134`): `SizeN` (x^{2+8ε−ϑ} ≤ n ≤ x^{2+8ε+ϑ}), `SizeM` (m ≈ x^{±ϑ}·√(x·δ₁)), `SizeK` (x^{9/2+10ε−ϑ} ≤ k ≤ x^{9/2+10ε+ϑ}), `SizeKRel` и ещё около двадцати условий. `SizeKRel` содержит 14 соотношений (посчитано по тексту определения), среди них `8·C_Γ·m⁵·f·L ≤ k` (условие 4), `k ≤ √x·n·rankBudget`, `m²·L ≤ k`, `m·√x·log x ≤ k`, `f ≤ m²·n`, `f ≤ r²`. `SizeKRel` не гипотеза: он доказан как теорема `szRow_sizeKRel` (`…/GlobalInterpolation/SzRowSizeKRel.lean:151`) подбором параметров `szTh`, `rankBudget`; `f_mul_m_le` из `…/DivisorProofs/DGamCoprime.lean:33` использует `SizeKRel`. Модули `SzRowSizeKRelStatement`, `SzRowSizeKRel`, `DGamCoprime`, `ElevenLe`, `SzRowElevenLeSplitBound` входят в импорт-замыкание `Main` (текстовая проверка, `member.py`-подсчёт), но это условие необходимо, а не достаточно: входит ли `SizeKRel` в 1 478 198 деклараций, от которых зависит `riemannHypothesis`, PDF не проверял («не запрашивались»), я тоже не определил (`OPEN`).
- **Поправка (2026-11-22, H12-UNIFIED-RESEARCH-01).** Ограничивающее условие — соотношение 4 `SizeKRel` (`√(k/m) ≤ rankBudget`), а не член (A) `k/n² ≤ x^{1/2}`; они совпадают только при ε = 0. Полная классификация 14 соотношений — `critical_dependencies.md` §B2, `verification/sizekrel_exponents.py`.
- **Что не решено.** Откуда берётся показатель 5 при m в условии 4 (рост k как m⁵·f): требует чтения Part III §III.8 и `DesignS.lean`. Остальные соотношения `SizeKRel` (кроме 4) в моей системе показателей не учтены; поэтому система выше — необходимая часть, полная система больше. `OPEN`.
- **Статус.** Система показателей (условия 1–5) `PROVED`; соответствие полному набору `SizesAt` и использование условия 4 в финальной теореме `OPEN`.

## Часть 2. Альтернативные мосты

### A. Универсальный принцип делимости (теоремы Ивасавы и тета-подъёмы заменить абстрактной леммой)
- **Что можно сформулировать абстрактно и доказать.** (II.3): для ненулевого целого Δ и 0 ≤ e_p ≤ v_p(Δ) выполняется Σ e_p log p ≤ log|Δ|. `PROVED` (тривиально).
- **Что используется на самом деле.** Взвешенная оценка валюаций при инертных p: v_p(Δ) ≥ Σ_h (a/p^h − w_{cell})₊ − O(1 + log_p a). Модельный случай (II.4)–(II.5) доказан в PDF для ряда l(X) = X + Σ X^{p^{2j}}/p^j; для эллиптической кривой с комплексным умножением на Z[i] проверены числа: A₅ = −12, A₉ = 3024, A₁₇ = 21 224 560 896 = 2⁸·3⁶·7²·11·211, v_p(A₁₇) = (6, 2, 1) при p = 3, 7, 11, v_p(A₂₀₁) = (75, 29) при p = 3, 7 — всё воспроизведено точно (`verification/check_lemniscate_valuations.py`). Значения v_p(A_j) лежат ниже модельной границы j(1/p + 1/p³ + …) на 0.4–0.9 при j = 17, 101, 201 и p = 3, 7, 11, что согласуется с поправкой −O(1 + log_p j).
- **Вывод.** Замена цепочки тета-подъёмов «более простым механизмом» требует доказать для общей кривой с CM то, что в PDF доказано для модельного ряда: целостность тета-ядер (гипотеза (B) = E7e). Абстрактная лемма без автоморфных конструкций не получена. Статус: `OPEN`; численные примеры `EXACT_COMPUTED`; модельная лемма (II.5) `SOURCE_TRACED` (в PDF доказана).

### B. Положительность и операторы (положительно определённая форма вместо части усреднения)
- **Анализ.** Положительность уже используется на уровне коэффициентов c(r) ≥ 0. Заменить усреднение по характерам квадратичной формой с ядром Вейля: критерий Вейля связывает положительность формы Вейля на всех тестовых функциях (носитель [−L, L] для всех L) с RH. Положительная определённость конечной матрицы Q_N(c) при заданных (N, c) — необходимое следствие RH для этой формы, не достаточное для неё. В серии B проекта H-12 она проверена в 334 ячейках (характеры по модулю до 79, N ≤ 96, интервальный сертификат n_neg = 0) — это факт о конечных матрицах.
- **Вывод.** Мост через положительность как независимое доказательство логически кругообразен, если требуется положительность для всех L и всех тестовых функций: она эквивалентна RH. Для конечных L она даёт конечномерное свидетельство, согласованное с RH, но не заменяющее неравенство (M). Статус: `REFUTED` как независимый мост без дополнительного входа; `OPEN` для варианта «ограниченный L».
- **Не смешивать.** Конечномерная положительность не доказывает положительность бесконечномерного оператора (ограничение контракта).

### C. Контроль исключительных интервалов без теории Ивасавы
- **Известное.** Минимальное условие на плохие масштабы для сохранения оконного критерия: экспоненциально малая мера исключительного множества внутри окна (RH-NEXT-01). Положительная плотность недопустима (W2).
- **Что требует (M) от плохих масштабов.** Хороший масштаб Y — тот, для которого найдены q, d с оценкой B на всём [Y, Y^{3/2}]; количество плохих масштабов оценивается среднеквадратичным методом (Part III.1, Estimate B). Без построения из Part III.1 информации о плохих масштабах нет.
- **Вывод.** Получить существование хороших интервалов без теории Ивасавы и без Estimate B не удалось. Статус: `OPEN`.
