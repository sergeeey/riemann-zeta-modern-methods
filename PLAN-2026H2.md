### B-01 · Репликация Connes 2026 ⭐ (приоритет 1)
- **Что:** arXiv:2602.04022 (Connes, фев 2026): экстремизация квадратичной формы Вейля
  даёт аппроксимацию нулей с точностью до 2.6×10⁻⁵⁵ на простых p < 13, и аппроксимации
  «лежат точно на критической прямой». Независимо воспроизвести таблицу.
- **Почему ценно:** результату 5 месяцев, независимых репликаций скорее всего нет;
  репликация свежего результата Филдсовского лауреата = publishable + идеальный кейс
  Skeptic Engine («аудит препринта топ-математика»). Кормит и G2, и G1.
- **EstimandOps L0:** descriptive (воспроизводится ли заявленная точность).
- **Falsifiable predicate:** наша реализация формы Вейля на p<13 воспроизводит заявленную
  точность в пределах 2 порядков; расхождение >2 порядков = FALSIFIED-репликация (тоже результат!).
- **Kill criteria:** (1) нужна машинерия за пределами mpmath/scipy и >2 сессий → park;
  (2) в статье нет достаточных деталей для репликации → результат «не реплицируемо по тексту» (тоже кейс).
- **Шаг 1 (30 мин):** прочитать §квадратичной формы в PDF, выписать формулу и параметры. CDT: до кода.

### B-02 · Nyman–Beurling / Báez-Duarte численно (приоритет 2)
- **Что:** вычислить d_N² = dist²(χ, span{ρ(θ/n)}) для N до ~10³–10⁴;
  сопоставить с гипотетической асимптотикой C/log N (C = 2+γ−log 4π... — сверить с литературой, не постулировать).
- **Почему:** атом не пройден проектом; «стена a/lnT» видна отсюда с новой стороны
  (медленность log N — та же стена в аппроксимационном языке). Прямое расширение SYNTHESIS.
- **L0:** descriptive. **Predicate:** убывание d_N² согласуется/не согласуется с C/log N на достижимых N.
- **Kill criteria:** численная нестабильность грамм-матрицы, не лечится за 1 сессию mpmath-точностью → park.
- **Осторожно:** плохо обусловленные грамм-матрицы — заранее negative control на известном подпространстве.

### B-03 · de Bruijn–Newman: динамика нулей под тепловым потоком (приоритет 3)
- **Что:** реализовать H_t для конечного приближения ξ, визуализировать движение нулей при t↑ и t↓,
  показать механизм «GUE-отталкивание ⟹ Λ≥0» (Rodgers–Tao) на картинке.
- **Почему:** соединяет A-09 (GUE) с дефомацией — новая грань стены; сильная фигура для landscape note (G3).
- **L0:** descriptive/illustrative. **Predicate:** пары нулей аннигилируют при t<0 в согласии с теорией.
- **Kill criteria:** конечное приближение ξ искажает динамику качественно → зафиксировать как caveat, не тянуть.

### B-04 · Матрицы Ганкеля коэффициентов Ли (приоритет 4, расширение A-06)
- **Что:** λ_n до n~50–100 через zero-free формулу (НЕ из нулей — урок A-06 о циркулярности!),
  проверить положительность миноров Ганкеля (λ_{i+j}) ⪰ 0 — это строже λ_n>0.
- **L0:** descriptive. **Predicate:** все главные миноры до N положительны / первый отрицательный минор найден.
- **Kill criteria:** zero-free вычисление λ_n дороже O(1 сессии) при n>30 → сузить n, честно указать окно.

### B-05 · Численная положительность формы Вейля (приоритет 5)

## 5. Механика гибкости (как план адаптируется)

1. **После каждого атома** — пересортировка бэклога по CDT-score:
   `score = (novelty × feasibility × вклад в G1-G3) / стоимость`. Записать 1 строку «почему следующий — этот».
2. **Pearl Gate** после каждой сессии: неожиданный testable инсайт → `pearl_registry` c next_check.
3. **Stop-rule:** 2 подряд NULL-сессии без pearls → Track R замораживается, фокус на G3 (упаковка того, что есть).
4. **Park-rule:** атом требует 3-ю сессию → автоматически park с revival condition. Никаких «ещё чуть-чуть».
5. **Branch-rule:** новая идея посреди сессии → строка в `sandbox/INDEX.md`, НЕ немедленная работа.
6. **Skeptic обязателен** (Step 8a, context asymmetry: только claim.md + код) перед любым PROMOTE.
7. **Ре-триггер плана:** новый значимый внешний результат (например, репликация B-01 удалась/провалилась) →
   пересмотреть весь бэклог, а не следовать плану инерционно.
