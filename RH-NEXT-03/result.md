# RH-NEXT-03 — Verified Spectral Continuation: результат (2026-11-22)

**СТАТУС: NEGATIVE** для центральной гипотезы (инкрементальная строгая сертификация через структуру скачка ранга один).
Побочные результаты (PARTIAL): точное описание того, где ранг один действительно есть; измеренный порог интервальной сертификации; сертифицированная вещественная точка перехода `c*(N=60)` для `D(s)`. Все побочные результаты малой новизны.
**L0:** структурный и алгоритмический (описательный и предиктивный). Утверждений о гипотезе Римана нет.

## 1. Постановка (зафиксирована до экспериментов)
Матрица `Q(c)`: матрица Галёркина формы Вейля CvS (arXiv:2511.23257, Prop. 4.1) без отсечения `T`, `L = log c`, базис `e^{2πinx/L}`, `n = −N…N`. Пилот: `χ₃` (a=3/4, q=3, без полюса), `D(s)` (a=3/4, q=5, веса `Λ_D(n)/√n` по всем `n ≤ c`). Гипотеза миссии: структура скачка ранга один на порогах позволяет обновлять строгие заключения об инерции без полной пересборки и факторизации на каждой точке `c`.
Точное определение «успеха»: меньшие суммарные затраты при тех же сертифицированных заключениях, измеренные на одном и том же классе задач.

## 2. Что доказано (аналитически, мой вывод; проверен числом, см. §3)
Для порога `y = log q` (`q` — степень простого или целое `n` для `D`) и веса `w`:
- Слагаемое `ψ_p^{(q)}(n; L) = −(w/π)·sin(2πn(1 − y/L))` для `L > y` и `0` для `L < y`. В точке `L = y` его значение и значение `ψ_p′` равны `0`, поэтому `Q(L)` **непрерывна** по `L`.
- `dψ/dL|_{L=y⁺} = −2w·n/y`, `dψ′/dL|_{L=y⁺} = −2w/y`. Тогда `d/dL (q_{mn})` получает скачок `−2w/y` одновременно во всех элементах: `(ψ(m) − ψ(n))/(m − n) → −2w/y` и диагональ `−2w/y`. То есть скачок производной равен `−2w/y · 𝟙𝟙ᵀ`, ранг один; для `ζ` это `−2Λ(q)/(√q log q)`. Совпадает с утверждением в статье 3 автора.
- **Следствие:** ранг один относится только к негладкой части пути. Между порогами `Q(L)` меняется гладко и во всех элементах.

## 4. Что из этого следует (INFERRED)
1. **Рост ранга.** Разность `Q(c₂) − Q(c₁)` между двумя вещественными отсечками с одним набором весов не имеет приближённо низкого ранга (B). Ранг один описывает только скачок производной на порогах, и тем самым пересчёт «известная часть плюс остаток ранга один» невозможен.
2. **Теория возмущений.** Абсолютная граница Вейля `λ_min/‖dQ‖ ≈ 10⁻²⁶` (C): для таких `Q` бесполезна. Относительное поведение собственного значения мягкое (`−20.5` на единицу `L`), но использовать это без структуры возмущения нельзя; конгруэнтной структуры `dQ/dL = XᵀQ + QX` (она сохранила бы инерцию по закону Сильвестра) я не нашёл и не доказал её отсутствие [UNKNOWN].
3. **Интервал по параметру.** Один интервальный `LDLᵀ` по окну `c` сертифицирует окно шириной всего `10⁻⁷⁰…10⁻⁷⁵` (D): интервальная факторизация раздувает радиус элементов примерно как квадрат числа обусловленности (`~10⁵²` при `cond ~10²⁶`), и порог лежит у `λ_min`-масштаба. Ни на какой практической сетке это не заменяет точечные сертификаты.
4. **Что реально экономит:** отслеживание перехода методом ложного положения с двумя сертификатами вместо бисекции со сплошными сертификатами: `~1.3×` при тех же сертификатах на концах (E). Это стандартный приём (несертифицированное отслеживание плюс апостериорный сертификат), к структуре ранга один отношения не имеет и в пределах разброса времени (±40%) малозначим.
