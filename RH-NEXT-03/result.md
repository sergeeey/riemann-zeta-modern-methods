## 1. Постановка (написана в задании до экспериментов; отдельного датированного артефакта нет, единственный коммит [UNKNOWN])
Матрица `Q(c)`: матрица Галёркина формы Вейля CvS (arXiv:2511.23257, Prop. 4.1) без отсечения `T`, `L = log c`, базис `e^{2πinx/L}`, `n = −N…N`. Пилот: `χ₃` (a=3/4, q=3, без полюса), `D(s)` (a=3/4, q=5, веса `Λ_D(n)/√n` по всем `n ≤ c`). Гипотеза миссии: структура скачка ранга один на порогах позволяет обновлять строгие заключения об инерции без полной пересборки и факторизации на каждой точке `c`.
Точное определение «успеха»: меньшие суммарные затраты при тех же сертифицированных заключениях, измеренные на одном и том же классе задач.

## 2. Вывод (ручной аналитический вывод [INFERRED]; сверен числом в A, но это та же формула, что в коде, а не независимый источник)
Для порога `y = log q` (`q` — степень простого или целое `n` для `D`) и веса `w`:
- Слагаемое `ψ_p^{(q)}(n; L) = −(w/π)·sin(2πn(1 − y/L))` для `L > y` и `0` для `L < y`. В точке `L = y` его значение и значение `ψ_p′` равны `0`, поэтому `Q(L)` **непрерывна** по `L`.
- `dψ/dL|_{L=y⁺} = −2w·n/y`, `dψ′/dL|_{L=y⁺} = −2w/y`. Тогда `d/dL (q_{mn})` получает скачок `−2w/y` одновременно во всех элементах: `(ψ(m) − ψ(n))/(m − n) → −2w/y` и диагональ `−2w/y`. То есть скачок производной равен `−2w/y · 𝟙𝟙ᵀ`, ранг один; для `ζ` это `−2Λ(q)/(√q log q)`. Совпадает с утверждением в статье 3 автора.
- **Следствие:** ранг один относится только к негладкой части пути. Между порогами `Q(L)` меняется гладко и во всех элементах.

## 4. Что из этого следует (INFERRED)
1. **Рост ранга.** Разность `Q(c₂) − Q(c₁)` между двумя вещественными отсечками с одним набором весов не имеет приближённо низкого ранга (B). Ранг один описывает только скачок производной на порогах, и тем самым пересчёт «известная часть плюс остаток ранга один» невозможен.
2. **Теория возмущений.** Абсолютная граница Вейля `λ_min/‖dQ‖ ≈ 10⁻²⁶` (C): для таких `Q` бесполезна. Относительное поведение собственного значения мягкое (`−20.5` на единицу `L`), но использовать это без структуры возмущения нельзя; конгруэнтной структуры `dQ/dL = XᵀQ + QX` (она сохранила бы инерцию по закону Сильвестра) я не нашёл и не доказал её отсутствие [UNKNOWN].
3. **Интервал по параметру.** Один интервальный `LDLᵀ` по окну `c` сертифицирует лишь окно шириной около `10⁻⁷⁰…10⁻⁷²` (D). Ни на какой практической сетке это не заменяет точечные сертификаты. Механизм порога **не установлен** [UNKNOWN]: прежнее объяснение «раздувание радиуса примерно как квадрат числа обусловленности, `~10⁵²`» измерением не подтверждено и снято. Измерено другое: радиус элементов матрицы при фиксированном окне растёт с точностью `prec` (в 7·10³ раз между 400 и 3000 бит при росте числа членов `K` с 49 до 337), то есть значительная часть ширины шара создаётся уже при построении матрицы, до факторизации. Порог D поэтому описывает нашу реализацию, а не внутреннее свойство семейства `Q(c)`, и как довод против интервального подхода слаб.
4. **Что реально экономит:** отслеживание перехода методом ложного положения с двумя сертификатами вместо бисекции со сплошными сертификатами: `~1.3–1.5×` при тех же сертификатах на концах (E). Это стандартный приём (несертифицированное отслеживание плюс апостериорный сертификат), к структуре ранга один отношения не имеет и в пределах разброса времени (±40%) малозначим.

## 6. Что нового получено нами и что не поддержано
- **Не поддержано проверенными экземплярами (вердикт NEGATIVE в узкой форме):** гипотеза «скачок ранга один даёт инкрементальную строгую сертификацию». Основание: B (гладкая часть полного ранга) и C (граница Вейля бесполезна). D измеряет иной механизм (одна интервальная факторизация) и по порогу зависит от реализации, поэтому довода против гипотезы не даёт. Цепочка обновлений ранга один не реализована и не измерялась. Опровергнуто также наше прежнее утверждение о возможной новизне результата по `D(s)` (§5).
- **Нового (малая значимость, новизна не проверена полностью):** (а) количественная картина B, C, D; (б) вещественная точка (одна из возможных; положительность на `(30, c*)` не проверялась) перехода `c*(N=60) ∈ [30.98938083885, 30.98938083985]` для `D(s)`: issue #57 формулирует первую неудачу на целой решётке `c`, то есть наша точка уточняет её, но не противоречит; (в) реальный выигрыш только `~1.3–1.5×` у стандартного метода.

## 6а. Чего результат НЕ означает
1. Не означает, что инкрементальная строгая сертификация инерции вдоль `Q(c)` невозможна: проверены один характер и один `D(s)`, по одному `N` и по одному диапазону `c` (`χ₃`, `c=23`, `N=16`; `D(s)`, `N=60`). Варьирование `c`, `N` и характера не проводилось.
2. Не означает, что пертурбационный подход бесполезен: проверена только абсолютная граница Вейля (C). Гладкое сертифицированное отслеживание собственного значения первого порядка не тестировалось; относительная чувствительность мягкая (`−20.5` на единицу `L`).
3. Не означает, что интервальная `LDLᵀ` по окну `c` неэффективна вообще: порог D зависит от точности построения матрицы (§4.3), то есть от нашей реализации.
4. Не означает установленный выигрыш `1.3–1.5×`: пять запусков на одной машине без интервала, базовая линия слабая (бисекция).
5. Не относится к гипотезе Римана и не меняет вывод RH-NEXT-02 о `D(s)` (повтор issue #57).
