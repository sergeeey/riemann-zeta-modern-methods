# Вариант B5: проверка масштабирования коэффициента при γ₁ по c (2026-11-22)

**Статус: NEGATIVE для проверяемой гипотезы, PARTIAL в целом.** Предрегистрация: `claim_B5.md` (прогнозы вычислены по c = 13, 23, 37 до новых расчётов, `results/predict_B5.log`). Данные: `results/parity_B5.jsonl` (80 новых ячеек: c = 53, 79; N = 64, 48). Анализ: `code/parity5_analysis.py`, журнал: `results/parity5_analysis.log`. Запуск: `code/run_B5.sh`.

## Итог в одной строке
Прогноз «коэффициент при γ₁ растёт примерно как −0.14·c» **не подтвердился**: при c = 53 и 79 наблюдается −5.25 и −3.76 вместо −7.5…−11.2, то есть рост остановился. Одновременно выяснилось, что при c ≥ 53 значения λ_min у самых важных для этого эффекта характеров (малый проводник, высокий первый нуль) при N = 64 ещё не сошлись, и на сошедших характерах эффект γ₁ при c ≥ 53 не обнаруживается.

## Предрегистрированная проверка (критерий 1: согласие при |набл − прогноз| ≤ 0.25·|прогноз|)
| модель | прогноз c=53 | прогноз c=79 | наблюдено (53, 79) | относительные ошибки | согласована при обоих c |
|---|---|---|---|---|---|
| A: β = −0.1418·c | −7.52 | −11.20 | −5.25, −3.76 | 0.30, 0.66 | нет |
| B: β = −1.1643·log c | −4.62 | −5.09 | −5.25, −3.76 | 0.14, 0.26 | нет (при c = 79 ошибка 0.26 чуть выше порога 0.25) |
| C: β = −0.427 − 0.1267·c | −7.14 | −10.44 | −5.25, −3.76 | 0.26, 0.64 | нет |
**Вердикт по правилу: ни одна из трёх форм не подтверждена.** Модели A и C (линейный рост по c) опровергнуты явно. Модель B отклонена по порогу 0.25; её ошибка при c = 79 (`0.26`) настолько близка к порогу, что различать её и «не подтверждена» по этим данным нельзя. Наблюдение «≈ −0.14·c» из B4 **снято**: оно возникло как экстраполяция трёх точек, и новые точки её не поддержали.

## Почему доверять значениям при c ≥ 53 нельзя без оговорок
- **Сходимость по N (критерий 4):** между N = 48 и N = 64 сошлись (`|Δ log₁₀ λ| < 1`) 17 из 20 характеров при c = 53 и только 14 из 20 при c = 79. Не сошлись: при c = 53 `D = −4` (6.6), `−3` (9.3), `5` (4.3); при c = 79 `D = −8` (4.0), `−7` (5.5), `−4` (10.6), `−3` (13.6), `5` (8.2), `8` (4.1) порядка.
- **Эти же характеры (малый проводник, высокий первый нуль) задают размах `γ₁`.** В подгонке по сошедшим характерам эффект исчезает: коэффициент при `γ₁` равен `−1.88` (`t = −2.1`, 17 характеров) при c = 53 и `−0.49` (`t = −0.7`, 14 характеров) при c = 79, при основной подгонке `−5.25` (`t = −4.6`) и `−3.76` (`t = −4.2`). Разный размах предиктора и малая мощность не позволяют различить «эффекта нет» и «эффект не измеряется».
- **Следствие:** вывод B3/B4 «высота первого нуля устойчиво обнаружена» установлен для c ≤ 37 (там почти все характеры сошлись), а при c ≥ 53 на N = 64 не подтверждён и не опровергнут.

## Описательно (не критерий решения)
- **Проводник:** вклад растёт с c и устойчив в обеих подгонках. Порядков на удвоение `q` (все 20): `1.45, 3.36, 6.19, 10.46, 16.88` при c = 13, 23, 37, 53, 79; по сошедшим при c = 53, 79: `+11.74 [t = 9.7]` и `+15.66 [t = 17.6]`. Деление на c даёт `0.112, 0.146, 0.167, 0.197, 0.214`: рост быстрее линейного. Закон не предрегистрирован и не проверялся.
- **Чётность:** `−2.04 [−1.1]` и `−0.52 [−0.4]` (все 20); `+0.72 [+0.6]` и `+2.24 [+2.6]` (сошедшие). Знак меняется между подгонками, по правилу не обнаружена; эффекты в несколько порядков не исключены (стандартные ошибки порядка 1–2).
- Подгонка: `R² = 0.973` и `0.989`, остаточное СКО `3.45` и `2.67` порядка (все 20); `1.92` и `1.30` (сошедшие).

## Проверки кода
Нарушений перемежаемости `λ(64) ≤ λ(48)`: 0 из 40 пар. Ненадёжных (близких к пределу точности собственного решателя) значений: 0. Сертифицированная инерция `n_neg = 0` во всех 80 ячейках. Ошибок в stderr нет.

## Что это означает для всей серии B (INFERRED)
1. Масштабный закон по c не установлен; прежняя гипотеза «−0.14·c» ошибочна.
2. Для малых проводников при c ≥ 53 значение `N = 64` недостаточно; чтобы измерять γ₁-эффект при этих c, нужно `N` порядка 96–128 и по несколько минут на ячейку (оценка по росту времени, не измерение).
3. Единственный фактор, устойчивый и по c, и по подгонкам, — проводник (но он не был предрегистрированным решающим критерием в B5).

## Ограничения
n = 20 (17 и 14 на сошедших), стандартные ошибки описательные, вещественные характеры, c ≤ 79, один код для всех ячеек (независимо подтверждена одна ячейка B3 и согласованность с теоремой о перемежаемости), линейная модель плохо описывает данные при больших c. Прогнозы строились по трём точкам; допуск 25% выбран заранее, но произволен (модель B при c = 79 отклонена на 0.01 выше допуска).
