## Как это читать (INFERRED)
1. Вердикт «γ₁ не обнаружен» нельзя читать как «эффекта нет». Исключение несошедшихся характеров убирает именно малопроводниковые образцы с высоким γ₁, то есть тот диапазон предиктора, который несёт эффект. Остаётся малая мощность (se 0.7–1.2 порядка).
2. Прежний вывод «γ₁ устойчиво обнаружен» (B3/B4) подтверждается только для c ≤ 37, где почти все характеры сошлись. При c ≥ 53 он не установлен и не опровергнут.
3. Несошедшиеся значения при c ≥ 53 не являются оценками предела. Проверить эффект можно лишь при N порядка 128 и выше (время растёт быстро, на одну ячейку уже около часа или меньше при N = 96; оценка, не измерение).
4. Чётность: стандартные ошибки 1–2 порядка, эффекты в несколько порядков не исключены; знак нестабилен.
5. Проводник — единственный фактор, одинаковый по знаку и значимости при всех c и всех выборках данных. Закон роста по c не предрегистрирован и здесь не проверялся.

## Чего результат НЕ означает

- Не распространяется на c ≫ 79 и комплексные характеры.
- Это описательный результат (L0): без причинной интерпретации «проводник вызывает».
