## Точная конструкция матрицы [VERIFIED по тексту CvS]
- Распределение D на [0, L], L = log c. Чётное продолжение D̃ живёт на [−L, L]; квадратичная форма определена на L²([−L/2, L/2]) (поэтому «[−log c, log c]» из постановки — это носитель D̃, а интегрирование идёт по y ∈ [0, L]).
- Функция ψ(x) = (1/π)·∫₀ᴸ sin(2πx(1 − y/L))·D(y) dy.
- Матричные элементы в базисе U_n (n = −N…N, размер 2N+1): q_{m,n} = (ψ(m) − ψ(n))/(m − n) при m ≠ n; q_{n,n} = ψ′(n). (Это согласуется с `kernels.py`: α = 2πx/L, множитель 2π в производной.)
- Важно для сертификатора: для целого x множитель sin(2πx(1−y/L)) = −sin(2πxy/L) обращается в 0 при y→0, и особенность ядра 1/(2y) в ψ(n) снимается. В ψ′(n) множитель равен 2π·cos(…) → 2π при y→0, и особенность ядра НЕ снимается: нужна конечная часть (регуляризованная пара), то есть аналитическое вычитание в u = 0, как требует постановка.

## Скрученный случай χ₃ [VERIFIED: Groskin §11]
- Архимедов вклад: ψ(1/4 + iτ/2) заменяется на ψ(3/4 + iτ/2) для нечётного характера; веса простых умножаются на χ₃(n).
- Для непринципального характера эйлерова полюса нет, значит полюсный член (формула с cosh(y/2) в `operator.py`) должен отсутствовать [INFERRED: в тексте не сказано, вытекает из отсутствия полюса у L(s,χ)].
- В u-пространстве ядро для ψ(a + iτ/2) равно e^{−2a·u}/(1 − e^{−2u}) (из интегрального представления дигаммы с t = 2u): a = 1/4 даёт e^{−u/2}/(1−e^{−2u}), a = 3/4 даёт e^{−3u/2}/(1−e^{−2u}). Это совпадает с ядрами из постановки [INFERRED, вывод по определению ψ; численно не сверялось].
- Разность архимедовых множителей: Re ψ(3/4 + iτ/2) − Re ψ(1/4 + iτ/2) = π/cosh(πτ) (из ψ(1−z) − ψ(z) = π·cot(πz), z = 1/4 + iτ/2) [INFERRED, вывод; численно не сверялось].
- Группа Q_c^{χ₃}: то, что у Гроскина названо «even/odd sector», — симметрия базиса матрицы (51 чётных и 50 нечётных собственных значений при 2N+1 = 101), а НЕ чётность характера.
