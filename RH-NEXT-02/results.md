## 2. Замкнутые формулы (мой вывод; проверены численно, см. §4)
Обозначения: L = log c, a = 1/4 + a_par/2 (a_par = 0 чётный, 1 нечётный характер), b = πn/L, ω = 2b, cₖ = 2k + 2a, z = a + ib.
- ψ_arch(n) = Im ψ(z)/(2π) − (ω/π)·Σₖ e^{−cₖL}/(cₖ² + ω²)
- ψ′_arch(n) = log(q/π) + Re ψ(z) + Re ψ′(z)/(2L) − (2/L)·Σₖ Re[e^{−cₖL}/(cₖ − iω)²]
- Простая часть: ψ_p(n) = −(1/π)·Σ w_m sin(2πn(1 − log m/L)), ψ′_p(n) = −Σ w_m·2(1 − log m/L)·cos(2πn(1 − log m/L)).
  Для χ: m — степени простых, w_m = χ(m)·log p/√m. Для D(s): m — все n ≤ c, w_n = Λ_D(n)/√n, где −D′/D = Σ Λ_D(n) n^{−s}.
- Полюсного члена у непринципального характера и у D(s) нет.
- q_{m,n} = (ψ(m) − ψ(n))/(m − n), q_{n,n} = ψ′(n), ψ(−n) = −ψ(n), ψ′(−n) = ψ′(n) (CvS Prop. 4.1).
Остаток геометрических сумм: ≤ e^{−c_K L}/(c_K²·(1 − e^{−2L})), шар расширяется на удвоенный остаток.

### Что из этого следует (INFERRED, цепочка)
1. Тождество Вейля vᵀQv = (1/L)·Σ_ρ f̂(ρ) проверено численно (§4).
2. Вклад нулей на критической прямой равен (1/L)·2·Σ|ξ̂(γ)|² ≥ 0.
3. Следовательно, vᵀQv < 0 для какого-либо v возможно только если у D есть нули вне прямой, и тогда в пределах разрешения базиса.
4. Известно, что у D такие нули есть (первый: 0.8085 + 85.699i, подтверждено).
Итог: сертифицированное отрицательное значение матрицы Q_D(c,N) подтверждает на уровне конечной матрицы, что форма Вейля для D не положительна. Пошаговое тождество проверено численно, но не доказано формально.
