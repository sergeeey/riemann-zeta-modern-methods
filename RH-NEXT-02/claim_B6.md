# Вариант B6: N = 96 для малых проводников. Предрегистрация (написана ДО запуска, 2026-11-22)

**L0:** описательный. Цель: выяснить, сходится ли λ_min у характеров с малым проводником при N = 96, и повторить вывод о высоте первого нуля (γ₁) на «лучших оценках» λ_min.

## Ячейки (14)
Характеры с q ≤ 8 при c = 53 и 79: D ∈ {−3, −4, 5, −7, −8, 8} (12 ячеек), и два несошедшихся при c = 37: D ∈ {−3, −4} (2 ячейки). Все несошедшиеся пары из B4 и B5 входят в этот список. N = 96. Собственные числа: mpmath 250 знаков при c = 37, 300 при c = 53, 400 при c = 79. Интервальный сертификат 2000 бит с автоудвоением до 16000. Ограничение времени ячейки: 3600 с; ячейка, не уложившаяся, считается отсутствующей и сообщается.

## Критерии (фиксированы до данных)
1. **Монотонность (проверка кода):** λ(96) ≤ λ(64) с допуском 10⁻⁶; нарушения сообщаются как дефект.
2. **Сходимость к N = 96:** пара «сошлась», если |log₁₀(λ(96)/λ(64))| < 1. Несошедшиеся исключаются из «лучших оценок» и называются.
3. **Лучшая оценка λ_min для (c, D):** N = 64 для характеров, уже сошедшихся на N = 64 (|Δ(48→64)| < 1); N = 96 для 14 ячеек выше, если они сошлись по критерию 2; иначе пара исключается.
4. **Повторная регрессия** на лучших оценках по каждому из c = 37, 53, 79 (модель как в B3–B5: log₁₀ λ_min ~ 1 + log₁₀ q + γ₁ + I(нечётный)), если сохранено не менее 10 характеров на набор. Фактор «устойчиво обнаружен на лучших оценках» при том же знаке, |t| ≥ 3 и |эффект| ≥ 0.5 порядка (q — на удвоение; γ₁ — на единицу; чётность — коэффициент при I(нечётный)) во всех трёх наборах; «устойчиво не обнаружен», если нигде нет |t| ≥ 3 при эффекте ≥ 0.5; иначе «неустойчив».
5. **Сопоставление:** коэффициенты при γ₁ на N = 64 (все 20), на сошедших N = 64 и на лучших оценках выводятся одной таблицей.
6. Все ячейки: сертифицированная инерция n_neg = 0; иначе исключаются и это указывается.

## Чего результат НЕ означает
1. Сходимость (изменение менее порядка между N = 64 и 96) не равна пределу при N → ∞.
2. Отсутствие сходимости при N = 96 не означает, что предел отсутствует: возможно, нужны N порядка 128 и выше.
3. Не распространяется на c ≫ 79 и комплексные характеры.
