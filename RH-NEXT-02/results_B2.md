# Вариант B2: расширенный набор характеров. Результаты (2026-11-22)

**Статус: PARTIAL, описательный.** Предрегистрация: `claim_B2.md` (до запуска). Данные: `results/parity_B2.jsonl` (40 ячеек), анализ: `code/parity2_analysis.py`, журнал: `results/parity2_analysis.log`. Запуск: `code/run_B2.sh`, затем `python parity2_analysis.py`.

## Что измерено
20 вещественных примитивных характеров (символы Кронекера `(D/n)`, `D ∈ {−3, −4, −7, −8, −11, −15, −19, −20, −23, −24}` нечётные, `D ∈ {5, 8, 12, 13, 17, 21, 24, 28, 29, 33}` чётные), `c ∈ {13, 37}`, `N = 16`. Во всех 40 ячейках интервальная `LDLᵀ` (2000 бит) даёт `n_neg = 0`: все матрицы положительно определены. Ошибок в `parity_B2.err` нет (только предупреждения sympy о будущем удалении `jacobi_symbol`). Эталон `γ₁` независим (`mpmath.dirichlet`, смена знака функции Харди).
Ячейки `D = −3, −8` дословно воспроизводят вариант B (`λ_min = 1.6852744·10⁻¹⁸` и `5.5123021·10⁻⁶`).

## Модель и решение по правилам, зафиксированным до данных
`log₁₀ λ_min ~ 1 + log₁₀ q + γ₁ + I(нечётный)`, МНК, n = 20 на каждое `c`. Разделимость `q` и `γ₁`: `corr(log q, γ₁) = −0.88`, число обусловленности плана 5.0 (оба порога соблюдены, `q` и `γ₁` разделимы по правилу; в урезанной подвыборке `q ≤ 13` при `c=13` `corr = −0.93`, там разделимость уже нарушена).
| фактор | `c = 13` | `c = 37` | решение по правилу |
|---|---|---|---|
| нечётность (порядков) | −0.48, t = −0.9 | +1.05, t = +3.5 | **не обнаружен** (знаки разные) |
| проводник (порядков на удвоение `q`) | +1.52, t = +2.5 | +6.62, t = +20.1 | **не обнаружен по правилу** (при `c=13` `|t| < 3`); направление согласовано |
| высота первого нуля (порядков на единицу `γ₁`) | −1.88, t = −5.5 | −0.94, t = −5.1 | **обнаружен** (один знак, `|t| ≥ 3`, `|коэф.| ≥ 0.5`) |
`R² = 0.960` (`c=13`) и `0.996` (`c=37`), остаточное СКО `1.03` и `0.55` порядка.

## Что из этого следует (INFERRED)
1. **Чётность как самостоятельный фактор не подтверждается.** Результат варианта B (чётный `χ₈` на 1.3–1.8 порядка меньше нечётного `χ₋₈`) совместим с `+1.05` порядка при `c=37`, но при `c=13` оценка нечётности малая, отрицательная и незначимая; остаточное СКО (`≈ 1` порядок) сопоставимо с самим эффектом.
2. **Главный фактор: высота первого нуля.** `λ_min` падает примерно на `1–2` порядка на единицу `γ₁`, одним знаком при обоих `c`. Это согласуется с интуицией «чем выше первый нуль, тем труднее форме Вейля быть почти вырожденной», но механизм не проверялся.
3. **Проводник:** вклад `log q` велик и растёт с `c` (`+1.5` порядка на удвоение при `c=13`, `+6.6` при `c=37`), но при `c=13` оценка неустойчива из-за коллинеарности с `γ₁`. Рост эффекта с `c` показывает, что зависимость не аддитивна по `c`.

## Ограничения (существенные)
- **Форма модели неточна.** Проверка остатков (предрегистрирована): корреляции остатков с квадратами центрированных предикторов `−0.55` (`log q`) и `−0.50` (`γ₁`) при `c=13`, `−0.44` и `−0.15` при `c=37`: умеренная вогнутость. Наибольшие остатки у `D = 29` (`−1.72` и `−1.04` порядка), `D = −3`, `D = −15`, `D = 17`, `D = 33`. `D = 29` выброс при обоих `c`; для `D = 29` и `33` проводник близок к `c = 37`, и причина не исследована.
- **Малая выборка и детерминированность.** n = 20, стандартные ошибки классические и описательные, не вероятностные. Один `N` (16). Вещественные характеры только.
- **Один код.** Все расчёты одним `cert_chi.py`; независимо подтверждены только эталонные нули `γ₁` и согласие `D = −3, −8` с вариантом B.
- **Новизна.** Предшественников по такому сравнению не найдено (два запроса; поиск не исчерпывающий). Не заявляется закон, только измеренная зависимость на сетке.

## Ошибка по ходу (не скрывается)
Первый запуск завис: мой символ Кронекера не обрабатывал `n = 0` (бесконечный цикл `while n % 2 == 0`), а `period(D)` вызывает его при `n = 0`. Для чётных `D` функция возвращала 0 раньше, поэтому завершились только 6 ячеек из 40 (`D = −4, −8, −20, −24, 8, 12`), остальные процессы крутились около 45 минут на ядро. Самотест начинался с `n = 1` и ошибку не ловил. Исправлено: правило `(a/0)`, самотест расширен на `n = 0` и длину периода; зависшие процессы остановлены; все 40 ячеек пересчитаны заново с журналом stderr.
