# Вариант B, расширение (B2): чётность против проводника и высоты первого нуля. Предрегистрация (написана ДО запуска, 2026-11-22)

**L0:** описательный, регрессия на детерминированных вычислениях. Причинных выводов о механизме нет. Это следствие вывода из B: порядок по λ_min следовал проводнику q (ρ = +0.97), γ₁ коррелировал (−0.90), чётность слабо (−0.29), но n = 5.

## Набор (20 вещественных примитивных характеров, символ Кронекера (D/n))
- Нечётные (D < 0): −3, −4, −7, −8, −11, −15, −19, −20, −23, −24.
- Чётные (D > 0): 5, 8, 12, 13, 17, 21, 24, 28, 29, 33.
Проводник q = |D|. Проверка в коде до использования: χ_D периодичен по модулю |D|, χ_D(−1) = sign(D), совпадение с таблицами B для D ∈ {−3, −4, 5, 8, −8}.

## Сетка и измерения
c ∈ {13, 37}, N = 16 (в B зависимость от N была слабой). 40 ячеек. В каждой: сертифицированная инерция (интервальная LDLᵀ, 2000 бит), λ_min (mpmath, 100 знаков), γ₁ из основного состояния и независимый эталон γ₁ из mpmath.dirichlet (по смене знака функции Харди).

## Модель (фиксирована до данных)
Для каждого c отдельно, OLS: y = log₁₀ λ_min на [1, log₁₀ q, γ₁, I(нечётный)], n = 20. Отчитываются коэффициенты с классическими стандартными ошибками (описательно: данные детерминированные, p-значений как вероятностей не интерпретируем), R², корреляция log q и γ₁, число обусловленности плана.

## Правила решения (до данных)
- «**Эффект чётности обнаружен**»: коэффициент при I(нечётный) одного знака в обеих ячейках c, |t| ≥ 3 в обеих, и |коэффициент| ≥ 0.5 десятичного порядка.
- «**Эффект проводника обнаружен**»: то же для log₁₀ q (в расчёте на удвоение q) с порогом 0.5 порядка на удвоение.
- «**Эффект высоты нуля обнаружен**»: то же для γ₁ (на единицу γ₁) с порогом 0.5 порядка на единицу.
- Если коррелированность log q и γ₁ такова, что |корреляция| > 0.9 или число обусловленности плана > 30, различение q и γ₁ объявляется **невозможным на этом наборе**, и порог для них не применяется.
- Если ничего не обнаружено: «эффект чётности (при контроле q, γ₁) на этом наборе не обнаружен».
- Итог для чётности формулируется только при сертифицированной инерции n_neg = 0 во всех 40 ячейках; иначе ячейка исключается и это указывается.

## Чего результат НЕ означает
1. Не доказывает отсутствия чётности как фактора при других c, N, при комплексных характерах и при q > 33.
2. Не объясняет механизм (кроме согласованности с гипотезой, что λ_min определяется q и γ₁).
3. Линейная модель по log q и γ₁ может быть неверной формы; нелинейность не исследуется (одна проверка остатков).
4. Для q > c (например D = 24, 28, 29, 33 при c = 13) число ненулевых простых весов мало; результат для этих ячеек отдельно помечается и анализируется с исключением и без.
