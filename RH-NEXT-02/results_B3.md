## Решения по предрегистрированным критериям устойчивости
- **Высота первого нуля γ₁: УСТОЙЧИВО ОБНАРУЖЕНА.** Один знак и `|t| ≥ 3` во всех 6 наборах; эффект от `−0.94` до `−3.09` порядка на единицу `γ₁`, то есть **величина зависит от `c` и `N`** (при `N = 32` в 1.8 раза (`c = 23`) и в 3.0 раза (`c = 37`) больше по модулю, чем при `N = 16`).
- **Чётность: НЕУСТОЙЧИВА.** Сильна (`|t| ≥ 3`, `≥ 0.5` порядка) только в одном наборе из шести (`c = 37`, `N = 16`: `+1.05`), знаки меняются (`+0.08`, `−0.42…−1.19`). Чётность как самостоятельный фактор не установлена.
- **Проводник: НЕУСТОЙЧИВ по правилу.** Один знак во всех шести, сильный в 4 из 6 (`c = 23, 37`), но не при `c = 13` (`t = 2.5` и `2.2`). Эффект растёт с `c` (`+1.5` при `c = 13` до `+7.3` порядка на удвоение `q` при `c = 37`).

## Сквозные проверки
1. **Сходимость по N.** Для 10 пар `(c, D)` изменение `λ_min` при переходе `N = 16 → 32` больше одного порядка: `c = 23`: `D = −4` (4.6), `−3` (8.5), `5` (2.4); `c = 37`: `D = −11` (1.1), `−8` (3.4), `−7` (5.1), `−4` (11.1), `−3` (14.6), `5` (8.4), `8` (3.6). То есть `N = 16` недостаточно для характеров с малым `q` при больших `c`, и значения `λ_min` в этих ячейках не являются пределом по `N`. Для `c = 13` разброс мал (медиана 0.01, максимум 0.95 порядка при `D = −3`).
2. **Независимое согласие:** `D = −3`, `c = 23`, `N = 16`: `λ_min = 2.2008303·10⁻²⁶` против `2.2008303·10⁻²⁶` от построителя на mpmath-квадратуре (`cvs_u.py`): относительное расхождение `0` в пределах 8 печатаемых знаков; **ПРОЙДЕНО**.
3. **Остатки:** корреляции остатков с квадратами центрированных предикторов: для `log q` от `−0.44` до `−0.55`, для `γ₁` от `−0.15` до `−0.51` (умеренная вогнутость во всех наборах, слабее всего для `γ₁` при `c = 37`, `N = 16`). Выброс `D = 29` в каждом из шести наборов (`−1.0…−3.5` порядка), `D = 17` в двух.

## Что это значит (INFERRED)
- Описание «`λ_min` убывает с ростом высоты первого нуля» подтверждается во всех сетках, но коэффициент не универсален: он растёт по модулю с `N` (то есть там, где `λ_min` лучше сошлась по `N`). Поэтому количественный «закон» по этим данным не определён.
- Вывод B2 о чётности (`+1.05` при `c = 37`) был артефактом наименее сошедшегося набора (`N = 16`, `c = 37`): при `N = 32` оценка `−0.42`, `t = −0.4`.
- Разброс остатков при `N = 32` вырос (до `1.97` порядка), потому что у малых `q` `λ_min` ещё уходит вниз с `N`.

## Ошибка, которую нужно прямо назвать
В `claim_B2.md` я написал «в B зависимость от N была слабой», и это **неверно** для больших `c`: в таблице варианта B при `c = 37` `χ₃` менялось с `4.6·10⁻³¹` (`N = 16`) до `1.2·10⁻⁴⁵` (`N = 32`), то есть на 14 порядков. Основание для выбора `N = 16` в B2 было неверным, и именно поэтому B2 показал наиболее «чистую» картину (`R² = 0.996`) там, где сходимость хуже всего. B3 это исправляет, но не устраняет: даже `N = 32` для части характеров может быть недостаточным (не проверялось).

## Ограничения
n = 20 на набор, классические стандартные ошибки (описательные), вещественные характеры, один и тот же код `cert_chi.py` для всех ячеек (независимо подтверждена одна ячейка), модель линейная и приближённая, `N → ∞` не достигнут. Новизна не проверялась сверх уже сделанного поиска.
