# Вариант B5: проверка масштабирования коэффициента при γ₁ по c. Предрегистрация (написана ДО запуска, 2026-11-22)

**L0:** предиктивный в узком смысле (проверка прогноза о форме зависимости на новых c), без причинных выводов.

## Гипотеза и конкуренты (подогнаны ТОЛЬКО по c = 13, 23, 37 при N = 64; `results/predict_B5.log`)
β(c) — коэффициент при γ₁ (порядков на единицу) в регрессии log₁₀ λ_min ~ 1 + log₁₀ q + γ₁ + I(нечётный), n = 20 характеров, N = 64. Наблюдено: β(13) = −2.021, β(23) = −3.434, β(37) = −5.078.
| модель | форма | невязки на 3 точках | прогноз c = 53 | прогноз c = 79 |
|---|---|---|---|---|
| A | β = −0.1418·c | −0.18, −0.17, +0.17 | −7.52 | −11.20 |
| B | β = −1.1643·log c | +0.97, +0.22, −0.87 | −4.62 | −5.09 |
| C | β = −0.427 − 0.1267·c | +0.05, −0.09, +0.04 | −7.14 | −10.44 |

## Новые ячейки
20 характеров (те же D) × c ∈ {53, 79} × N ∈ {64, 48}: 80 ячеек (N = 48 нужен для критерия сходимости). Собственные числа: mpmath 300 знаков при c = 79, N = 64; 250 при c = 53, N = 64; 200 при N = 48. Интервальный сертификат 2000 бит с автоудвоением до 16000.

## Критерии (фиксированы до данных)
1. **Прогноз согласуется с наблюдением** при данном c, если |β_набл − β_прогноз| ≤ 0.25·|β_прогноз| (коэффициент β_набл из той же регрессии на всех 20 характерах при N = 64).
2. **Победитель:** модель, согласованная при обоих c с наименьшей наибольшей относительной ошибкой; если согласованы A и C (расхождение прогнозов 5–7%, ниже разрешения данных), они объявляются **неразличимыми**, и вывод формулируется как «приблизительно линейно по c», без выбора между ними. Если согласована только B, это называется явно. Если ни одна не согласована при обоих c: «ни одна из трёх форм не подтверждена».
3. **Надёжность значений:** ячейка с λ_min < 10^(−(dps − 60)) помечается ненадёжной (собственный решатель мог потерять точность) и исключается из подгонки; факт указывается.
4. **Сходимость:** пара (c, D) «сошлась к N = 64», если |log₁₀(λ(64)/λ(48))| < 1. Повторить подгонку только по сошедшимся, если их не менее 10 на набор. Основной вердикт по критерию 1 берётся по всем 20, дополнительный по сошедшимся.
5. **Проверка кода:** λ(64) ≤ λ(48) (перемежаемость, допуск 10⁻⁶) для всех 40 пар; нарушения — дефект, не данные.
6. Сертифицированная инерция n_neg = 0 во всех 80 ячейках; иначе ячейка исключается и это указывается.
7. Повторно сообщаются коэффициенты при чётности и проводнике (без критерия решения, описательно).

## Чего результат НЕ означает
1. Совпадение с A или C на двух новых c не доказывает закон: форма проверена на пяти значениях c ≤ 79.
2. Согласие с прогнозом при выборочных стандартных ошибках порядка 1–2 порядка по β не различает близкие формы.
3. Ничего не говорится о c ≫ 79 и о причине зависимости.
