Данные: `results/parity_B4.jsonl` (120 новых ячеек: N = 48, 64), вместе с B2 и B3 по каждой из 60 пар (c, D) получены последовательности N = 16, 32, 48, 64 (240 ячеек). ## Итог в одной строке
`N = 64` достаточно (`λ_min` сошлась в пределах одного порядка между `N = 48` и `64`) у 58 из 60 пар; из всех факторов устойчиво обнаруживается только высота первого нуля (`γ₁`), и её эффект растёт с `c`; чётность по-прежнему не обнаружена, а прежний «эффект чётности» из B2 был артефактом несошедшегося `N = 16`.

## Проверки
1. **Монотонность (проверка кода): нарушений 0 из 60 последовательностей.** `λ_min(16) ≥ λ_min(32) ≥ λ_min(48) ≥ λ_min(64)` везде (допуск `10⁻⁶`), как требует теорема о перемежаемости (`Q_N` — точная главная подматрица `Q_{N+1}`). Это независимая внутренняя проверка согласованности вычислений для всех 240 ячеек.
2. **Сходимость к `N = 64`:** `c = 13`: 20 из 20; `c = 23`: 20 из 20; `c = 37`: 18 из 20 (не сошлись `D = −3` и `D = −4`; изменение `λ_min` между `N = 48` и `64` у `D = −3` равно 5.0 порядка). По правилу «не менее 18 из 20» `N = 64` достаточно при каждом `c`, но у `c = 37` вплотную.
3. **Скорость** (медиана / максимум `|log₁₀(λ(N₂)/λ(N₁))|` по 20 характерам):
   | c | 16→32 | 32→48 | 48→64 |
   |---|---|---|---|
   | 13 | 0.01 / 0.95 | 0.00 / 0.08 | 0.00 / 0.04 |
   | 23 | 0.12 / 8.54 | 0.02 / 2.23 | 0.01 / 0.12 |
   | 37 | 0.23 / 14.59 | 0.05 / 8.81 | 0.03 / 5.01 |
   Максимумы всюду у `D = −3` (самый малый проводник). `χ₃` при `c = 37`: `4.6·10⁻³¹` (`N = 16`) → `1.2·10⁻⁴⁵` (`N = 32`) → `1.8·10⁻⁵⁹` (`N = 64`).

Вердикты (правила как в B3, три набора по `c`):
- **Высота первого нуля: УСТОЙЧИВО ОБНАРУЖЕНА** (и при `N = 32`, и при `N = 64`, и на сошедших парах): один знак, `|t| ≥ 3` везде.
- **Чётность: УСТОЙЧИВО НЕ ОБНАРУЖЕНА** при `N = 32` и `N = 64` (ни в одном наборе `|t| ≥ 3`). Но точечные оценки при `N = 64` не малы (`−0.6, −1.5, −2.5` порядка) и стандартные ошибки велики (`≈ 0.6, 1.2, 1.8`, то есть 95%-интервал при `c = 37` приблизительно от `−6` до `+1` порядка): отсутствие эффекта не доказано, эффекты до нескольких порядков **не исключены**. На сошедших парах знак оценки меняется (`+0.68`).
- **Проводник: НЕУСТОЙЧИВ** (один знак везде, сильный только при `c = 37`).

## Что изменилось по сравнению с B2 и B3 (INFERRED)
- Прежний «эффект чётности» `+1.05` (`c = 37`, `N = 16`) исчез: при `N = 64` оценка `−2.52`, `t = −1.4`. Он возникал из-за несошедшейся `λ_min` у малых `q` при `N = 16`.
- Коэффициент при `γ₁` по модулю растёт с `c`: `−2.0`, `−3.4`, `−5.1` порядка на единицу (`N = 64`). Деление на `c` даёт `−0.155`, `−0.149`, `−0.137`, то есть по трём точкам примерно `−0.14·c`. Это только наблюдение по трём значениям `c` и не проверялось (не предрегистрировано); теоретического обоснования нет.
- Подгонка линейной моделью ухудшается с ростом `c` (СКО `1.13 → 2.21 → 3.36` порядка при `N = 64`), так что количественная форма зависимости не определена.

## Ограничения
n = 20 на набор (18 на сошедшем), классические стандартные ошибки (описательные), вещественные характеры, `c ≤ 37`, один код для всех ячеек (независимо подтверждена только `D = −3, c = 23, N = 16`; согласованность с теоремой о перемежаемости подтверждена на всех ячейках). Сходимость `|Δ| < 1` порядка между `N = 48` и `64` не доказывает предела; у `D = −3, −4` при `c = 37` она не достигнута. Новизна не проверялась сверх уже сделанного поиска.
