# Вариант B4: сходимость λ_min по N. Предрегистрация (написана ДО запуска, 2026-11-22)

**L0:** описательный. Цель: выяснить, при каком N λ_min(c, D, N) перестаёт заметно убывать, и перепроверить выводы B3 (устойчив только γ₁) на сошедшихся значениях.

## Теоретический факт для проверки кода (доказан здесь, не измерен)
Q_N есть главная подматрица Q_{N+1}: индексы n = −N…N вложены, а элементы q_{m,n} = (ψ(m) − ψ(n))/(m − n), q_{n,n} = ψ′(n) не зависят от N. По теореме о перемежаемости (Коши) λ_min(Q_{N+1}) ≤ λ_min(Q_N). Значит λ_min(c, D, N) не возрастает с N, и предел по N существует (может быть положительным: infimum формы на функциях с носителем длины L; см. Zhu, arXiv:2608.24827, где этот infimum положителен).

## Новые ячейки
20 характеров (те же D, что в B2/B3) × c ∈ {13, 23, 37} × N ∈ {48, 64}: 120 ячеек. Вместе с N = 16, 32 из B2 и B3 получаются последовательности по N = 16, 32, 48, 64 для каждой из 60 пар (c, D). Точность: собственные числа mpmath 160 знаков при N = 48 и 250 знаков при N = 64; интервальный сертификат 2000 бит с автоудвоением до 16000 при неопределённости.

## Предрегистрированные проверки и критерии
1. **Монотонность (проверка кода):** для каждой пары (c, D) λ(16) ≥ λ(32) ≥ λ(48) ≥ λ(64) с относительным допуском 10⁻⁶ на печатную точность. Любое нарушение считается дефектом кода или точности и сообщается отдельно, не как данные.
2. **Сходимость по N:** пара (c, D) «сошлась к N = 64», если |log₁₀(λ(64)/λ(48))| < 1. Для каждого c: «N = 64 достаточно», если сошлись не менее 18 из 20 характеров; иначе «N = 64 недостаточно при этом c».
3. **Скорость:** медианы и максимумы |log₁₀(λ(N₂)/λ(N₁))| для переходов 16→32, 32→48, 48→64 по каждому c.
4. **Перепроверка выводов B3.** На наборах N = 64 (по одному на c) применяется та же регрессия и те же правила, что в B2/B3: log₁₀ λ_min ~ 1 + log₁₀ q + γ₁ + I(нечётный). Фактор «устойчиво обнаружен на N = 64», если во всех трёх наборах (c = 13, 23, 37) один знак, |t| ≥ 3 и |эффект| ≥ 0.5 порядка (q — на удвоение, γ₁ — на единицу, чётность — коэффициент при I(нечётный)); «устойчиво не обнаружен», если нигде нет |t| ≥ 3 при эффекте ≥ 0.5; иначе «неустойчив». Те же три набора пересчитываются только по сошедшимся парам (если сошедших не менее 10 на набор).
5. **Сопоставление с N = 32:** коэффициенты при N = 32 (B3) и N = 64 сравниваются в таблице; изменение вывода (обнаружен ↔ не обнаружен) называется явно.
6. Все 120 новых ячеек: сертифицированная инерция n_neg = 0; иначе ячейка исключается и это указывается.

## Чего результат НЕ означает
1. Не доказывает сходимость к пределу при N → ∞: отсутствие изменения в один порядок между N = 48 и 64 ещё не предел.
2. Не говорит ничего о c ≫ 37 и о комплексных характерах.
3. Положительный предел λ_min для данной (c, D) не доказывается; это наблюдаемое поведение.
