# Claim (предрегистрация, до запуска)

**Источник утверждения:** arXiv:2605.20224v2, §8.10 и введение (пункт 5): отрицательные собственные значения при c=23, 29 — артефакт T=400, исчезают при большем T. Числа в тексте: −6.46·10⁻²³ (c=23) становится положительным к T=800; −5.82·10⁻¹⁷ (c=29) к T=1200. Прогон с этими T в тексте не найден; таблица 18 неоднозначна по назначению чисел.

**Критерии (фиксируются до запуска):**
- ПОДТВЕРЖДЕНО: при T ≥ 800 знак положительный, при T = 1200 — положительный; картина повторяется при dps 300.
- ОПРОВЕРГНУТО: отрицательный знак сохраняется при T = 1200 при dps 150 и dps 300 — артефакт не cutoff.
- ЗАВИСИТ ОТ ТОЧНОСТИ: знак меняется с dps, но не с T — это артефакт точности, не cutoff.
- НЕ РЕШЕНО: знак меняется немонотонно по T — записать как неоднозначное, не подтверждать.
- Контроли: c = 13 должен оставаться положительным при всех T; ζ-версия при c = 23 — сверка с опубликованным (если доступно).

**Ограничение:** до запуска не известно, существует ли χ3-реализация в доступном коде. Развилка — шаг 2 плана.

## Шаг 1 — подтверждение кода (substrate gate), 2026-10-17

- Пакет `connes-cvs` 0.2.2 не установлен локально (`pip show` пуст). Колесо скачано в scratchpad без установки: `connes_cvs-0.2.2-py3-none-any.whl`.
- Официальный репозиторий из статьи: `akivag613/connes-cvs-`, существует, последний push 2026-10-15. Адрес `nrensen/connes-cvs-` из поиска отвечает 404, не использовать.
- **χ₃ в публичном пакете отсутствует.** Пакет жёстко зашит под ζ в двух местах:
  - архимедов член `h_plus(τ) = Re ψ(1/4 + iτ/2) − log π` (гамма-множитель ζ; для нечётного χ₃ нужен другой);
  - веса простых `Λ(p^k) = log p` (для χ₃ нужно χ(p)·Λ(p^k)), плюс полюсный член, которого у L(s,χ) нет.
- Параметр `T` в публичном API есть: `build_galerkin_matrix(c, N, T, dps)`. Для ζ T-тест выполним без портирования.
- Зависимости (`mpmath` 1.3.0, `python-flint`, `numpy`) установлены.
- Вывод: порт на χ₃ — самостоятельная работа (дни), либо нужны вспомогательные скрипты из Zenodo-архива статьи (не проверялись).

## Шаг 3 — предварительный дзета-контроль (N=20, dps=80, один прогон на T), 2026-10-17

Не финальный протокол (N=20 вместо 100, один dps). Код: `connes_cvs` 0.2.2, `build_galerkin_matrix` + `compute_ground_state`.

| T | λ_min (ζ, c=23, N=20, dps=80) |
|---|---|
| 400 | +1.03·10⁻⁴⁷ |
| 800 | +1.07·10⁻⁴⁷ |
| 1200 | **−1.20·10⁻²⁰** |

Наблюдение: знак меняется с ростом T в направлении, противоположном утверждению статьи (там отрицательное исчезает при большем T). Это НЕ подтверждает и НЕ опровергает утверждение о χ₃; это контрольный результат для ζ при малом N. Возможные объяснения, которые надо разделить: (а) зависимость от N, (б) ошибка точности (проверка dps=120 идёт), (в) немонотонность по T в самом коде.
