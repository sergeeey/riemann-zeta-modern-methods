# Estimand — 20261017-chi3-T-artifact

**L0 type:** Descriptive (численное свойство фиксированного оператора как функции cutoff T). Не causal.

**Natural-language statement:** Мы оцениваем знак наименьшего собственного значения чётного сектора CvS-оператора для L(s,χ3) при c ∈ {23, 29}, N = 100, сравнивая T ∈ {400, 800, 1200}, и сравнивая dps 150 и 300, для сравнения эффекта cutoff с эффектом точности.

| Поле | Значение |
|---|---|
| Population | CvS-оператор для L(s,χ3) при c ∈ {13, 23, 29, 37}, N = 100 (контроль c = 13) |
| Intervention | Архимедов cutoff T ∈ {400, 800, 1200} |
| Comparator | Тот же оператор при T = 400 (как в статье v2) |
| Endpoint | Знак и значение наименьшего собственного значения чётного сектора |
| Summary measure | Разность значений (абсолютная), сравнение знаков |
| MCID | Знак (положительный / отрицательный). Значение порядка 10⁻²⁰ считается значимым только при сохранении знака при повышении dps |
| ICE | Не применимо: оператор фиксированный, постбейзлайн-событий нет |

**What this result does NOT mean:**
1. Не доказывает и не опровергает RH и не говорит о сходимости к нулям χ3.
2. Не говорит, что χ3-сходимость для c = 13, 17, 37 верна за пределами протестированных c.
3. Не является проверкой других характеров (χ4, χ5, χ7) и не проверяет D(s).
