# Controls — B-02

## Positive control — none applicable
Нет независимого "known-good" источника с опубликованными числовыми значениями I_N для
сверки один-в-один (Bettin–Conrey–Farmer публикуют только асимптотику, не таблицу I_N(N)).
Вместо positive control используется analytic negative control (ниже) + no-collapse test.

## Negative control — V_N ≡ 0
**Расчёт:** при V_N(s)≡0 формула вырождается в I = (1/2π)∫dt/(¼+t²) = (1/2π)·2π = 1
(аналитически точно, ∫_{-∞}^{∞} dt/(a²+t²) = π/a, a=½).

**Наблюдение [VERIFIED-tool, run_b02.py]:** I(V=0) = 0.9992042257 (t_cutoff=400, dps=30).
Совпадает с аналитическим 1.000 с точностью ~0.08% (остаточная погрешность — обрезание
хвоста интеграла на t=400, не бесконечность).

**Вывод:** нормировка формулы (множитель 1/π вместо 1/2π, учитывающий чётность интегранда
и половинный диапазон [0,∞)) реализована верно.

## No-Collapse Test — устойчивость к схеме квадратуры
**Что менялось:** breakpoint-сетка `mp.quad` при фиксированном N=10:
- original (coarse): [0,5,20,50,100,400] — 6 точек
- linear fine to 400: шаг 2, 201 точка
- linear fine to 1000: шаг 2, 501 точек, t_max=1000
- very fine to 200: шаг 0.5, 401 точка

**Результат [VERIFIED-tool, diagnose_quad.py]:**
| Схема | I_N (N=10) |
|---|---|
| coarse (original) | 0.700617083 |
| fine→400 | 0.700617083 |
| fine→1000 | 0.700792378 |
| very fine→200 | 0.700326926 |

Разброс между схемами ≤0.03% — интеграция СТАБИЛЬНА. Хвост [400,5000] = 0.000269 —
пренебрежимо мал.

**Вывод: квадратура НЕ является источником наблюдаемого роста I_N с ростом N.**
Substrate Gate (estimand.md ICE #1) → READY, результат засчитывается за/против самого claim'а.

## Дополнительная диагностика — поточечное поведение V_N(½)
Не входит в формальный no-collapse чек-лист (это не вариация теста, а декомпозиция сигнала),
но объясняет механизм роста I_N:

| N | V_N(½) | \|1−V_N(½)\| |
|---|---|---|
| 10 | 0.1013 | 0.8987 |
| 30 | −0.1394 | 1.1394 |
| 100 | −0.2829 | 1.2829 |
| 300 | −0.3638 | 1.3638 |
| 1000 | −0.4166 | 1.4166 |
| 3000 | −0.4573 | 1.4573 |

t=0 доминирует вес 1/(¼+t²) (максимум веса ровно в t=0) → ухудшение именно в этой точке
напрямую тянет I_N вверх. Это НЕ артефакт интегрирования (см. no-collapse выше) — это
реальное поведение самого V_N(½) на исследованном диапазоне N.
