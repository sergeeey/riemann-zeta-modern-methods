## 1. Итог

Доказательства или опровержения RH нет ни у кого. Единственный реальный сдвиг — доля нулей,
простых и на прямой, ≥ 0.6725 (Alpöge–Furman arXiv:2608.13637, независимо Lamzouri
arXiv:2609.02882). Потолок класса bandwidth-one сертификатов ≈ 0.682 (в статье p0 ≤ 0.6818287,
не 0.68185 — это из блога). Метод «не различает две трети и все» (§7.2, цитата подтверждена
чтением PDF). Никто потолок не пробил [VERIFIED-tool: статьи; поиск ≠ доказательство отсутствия].

## 5. Разбор `RH_исследование_отчет.md` (внешний отчёт «Scientific Research Agent v2.0»)

Научной новизны нет: пересчёт констант, проверка Prop 2.1 на синтетике, «слепота к o(N)» =
§7.2 статьи, барьеры = собственные теоремы авторов, Davenport–Heilbronn известен с 1936
(наш B-07). Ценность — курирование карты барьеров.

Подтверждено по PDF: цитата §7.2; оптимальность C_MT только «among windows» (CCLM17 Cor.14),
потолок всего класса «≈ 0.682»; Zhu: A_L≈4e^L, T1=2πe^{A_L}, «requires cancellation in the
prime comb», поддержка 1.6.

Ошибки отчёта:
1. C-006 «mdumitrean 0.67280 противоречит теореме» — НЕВЕРНО: 0.6728 < потолка 0.6818; PR
   использует «six-translate Montgomery–Taylor penalty», то есть выходит за одно окно. Отчёт
   пишет «содержимое PR недоступно», хотя оно публично (прочитано через GitHub API, 2026-08-30:
   0.6727556 → 0.6727837 → 0.6727949 → 0.6728006, всё не смёржено). Внутреннее противоречие:
   сам приводит 0.6730 (Ainta) и 0.67251 (census) выше 0.6725.
2. Потолок «0.68185 (Remark 1.1)» — в статье 0.6818287 / «≈ 0.682».
3. «Prop 2.1 confirmed, high» — на самом деле [VERIFIED-SYNTHETIC]; ядро менялось после первых
   «нарушений»; сам автор признаёт (adversarial п.5), что тест слаб как дискриминатор.
4. «H-001/H-002 falsified как путь к RH» — сильнее источников: барьеры доказаны для классов
   методов, не для задачи.
5. Не проверить: скрипт `rh_wall_computation.py` не приложен; цитата «gap between knowing
   where the zeros are…» в тексте Zhu не найдена.
Дёшево и полезно: EXP-005 (`findroot` secant→bracketing) — уже найдено нами независимо;
EXP-006 (независимый прогон Lean-сертификатов) — не сделано.
